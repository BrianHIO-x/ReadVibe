# 阅读与书架操作

应用内的确认、输入、操作面板和短提示跟随当前阅读主题，使用统一的圆角、文字、按钮和间距；系统文件选择及外部应用界面由 Android 或对应应用提供。

## 书架

通过导入按钮选择本地书籍（支持在系统文件选择器中长按一次多选多本书同时导入），导入完成后点击书卡阅读。书架支持按书名、作者或格式搜索，以及自定义分组、最近阅读、未读和格式筛选。搜索会自动对齐全角与半角，输入 `（5）` 或 `(5)` 都能找到同一本书。当前筛选显示在搜索框下方，可单独清除；筛选菜单和标签跟随当前主题。

搜索框下方提供书架分组栏：默认保持收起状态，需要时可通过右上角“筛选”菜单中的“显示分组栏”或直接点选分组展开，并在栏尾点击“收起”或再次经筛选菜单隐藏。分组栏可切换分组浏览，或点击“新建分组”/“管理分组”新建、重命名、删除自定义分组（最多 64 个）。普通书架与隐私书架的分组彼此独立、互不互通，移入或移出隐私书架时不会混用另一侧的分组目录。

每行放几本书由屏幕宽度决定。竖屏手机保持三列，横屏和平板会自动增加列数，书卡尺寸保持不变。书卡都停在系统手势条上方时，上下滑动不会带动书架。书卡超出可视区域后可以滚动，滚到底时最后一排停在系统手势条上方。

书卡优先显示书里自带的封面图，书名放在封面下方。没有封面图或封面读取失败时，书卡以文字显示书名和作者。

同一个文件可以重复导入。第二本起书名后面自动加编号，两本书各自保存正文、阅读进度、章节编辑和书签，删除其中一本不影响另一本。

Word 文档按边读边解析的方式导入，几百万字的长篇也能读进来，不再因为文件稍大就失败。Word 用内容控件包住的正文同样会被读出。超长段落或章节采用普通排版，以缩短打开时的等待。

TXT 会自动识别编码，除 UTF-8、GBK、Big5 之外，没有字节序标记的 UTF-16 文件也能正确读出。

长按书卡可以修改书名和作者、设置所属分组、进入排序界面、移入或移出隐私书架、导出文件或删除书籍。排序时拖动书卡调整位置，完成后保存顺序。

点击书架顶部的“多选管理”图标或长按书卡选择“多选管理”即可进入批量管理模式（此时顶部搜索、筛选与分组栏会自动收起，勾选态仅在当次使用有效）：可点选多本书籍，或一键全选/取消全选当前可见书籍，通过底部操作栏批量分配分组、批量移入或移出隐私书架，或批量删除。

点击书架顶部的菜单按钮以后，设置面板会从左侧滑出。拖动时它会紧跟手指，拖过四成宽度或者快速向左一甩就会收起，拖得不够时会弹回原位。

## 隐私书架

在书架页打开左侧设置，点击“设置隐私书架”就能开启这个功能。开启时需要先设置 6 位数字密码，随后可以选择是否使用指纹或人脸验证。两种生物验证可以只开一种，也可以同时开启。

同时开启两种验证时，可以在“验证方式与密码”里选定默认的一种。进入隐私书架的时候，系统会先弹出这种默认验证。如果取消这次验证，也可以改为输入密码。

按照安卓系统的规则，验证框接受哪种生物信息由系统决定。手机同时向应用开放指纹和人脸时，两种方式都可能通过验证。如果手机的人脸解锁只用于锁屏，设置里的人脸选项就会显示为不可用。

进入以后，书架只会显示隐私书籍。长按普通书架里的书卡并选择“移入隐私书架”，就能把它移动到这里。在隐私书架里导入的新书，会直接归入隐私书架。

离开应用以后，默认会就地覆盖全屏隐私锁屏遮罩（可在隐私设置调整“后台自动锁定”为立即锁定、1 分钟后或 5 分钟后）：底层原本正在浏览的隐私书架或隐私书籍页面栈保持不变，返回应用或冷启动重启后通过验证即可直接回到当前阅读页面，按返回键仍停留在隐私书架，或在锁屏页面主动点击“返回普通书架”。打开隐私书架、隐私阅读页或锁屏遮罩期间，应用会自动开启系统安全窗口标记（`FLAG_SECURE`），禁止多任务缩略图、截屏与录屏露出页面内容；主动点击顶部“锁上”或切回普通书架后即解除。

忘记密码时，可以点击密码键盘下方的“忘记密码”。已经开启指纹或人脸验证的话，验证通过后就能设置新密码。

两种验证都没有开启时，只能清空隐私书架后重新设置。清空操作会删除其中的全部书籍，并且无法恢复。

连续输错 5 次密码以后，需要等待一段时间才能再次输入。之后每次输错，等待时间都会加倍，最长为 15 分钟；倒计时结合系统单调运行时间与开机计数校核，单纯修改系统时间不会提前解除锁定。

在“验证方式与密码”里关闭隐私书架以后，其中的书籍会移回普通书架。隐私书架只负责在书架上隐藏书籍，不会额外加密正文。

## 阅读恢复与数据安全

- **冷启动恢复上次阅读**：默认启用。从书架打开任意书籍后，若中途划掉后台或进程被系统回收，下次打开 ReadVibe 会自动回到上次正在阅读的书籍及位置（由外部文件管理器直接打开新书时则优先导入新书）；进入隐私书籍前会先经过隐私锁屏遮罩验证。可在全局设置中的“阅读恢复”随时关闭。
- **防卸载守护目录**：从全局设置进入“数据安全与备份”，可在“防卸载守护目录”页签绑定外部目录。默认采用零敏感权限的 SAF（`ACTION_OPEN_DOCUMENT_TREE`）并优先定位到 `Documents` 避免系统目录选择器在内部存储根目录报错；也可按需切换“应用内自选目录（高级）”（触发授权“管理所有文件”权限后通过主题化目录浏览弹窗在本地目录中浏览、新建子文件夹或识别已有 `ReadVibe_Vault` 备份后直选绑定）。开启后应用会以有界 64 KB 流式 I/O 在 `ReadVibe_Vault/` 中按书增量同步正文、笔记、书签、进度、分组与自定义字体，并提供 512 MB / 1 GB / 2 GB / 4 GB / 不限配额与设备 256 MB 最低可用空间余量保护；隐私书架默认不参与外部守护同步（开启或关闭后随时可一键彻底清理）。支持仅解绑目录（保留外部备份）、校验清理冗余临时/孤立包、清空守护目录以及卸载重装后一键扫描恢复。
- **便携压缩包 (.zip)**：切换到“便携压缩包 (.zip)”页签可打包或合并恢复单文件全量 `.zip` 快照，适合跨手机换机迁移。

## 导出文件

长按书卡，选择“导出文件”，在系统保存界面选择文件名和位置。文字书按章节顺序导出为 UTF-8 TXT，包含已保存的本地编辑内容；图片和富文本排版不包含在 TXT 中。PDF 导出应用保存的当前文件副本。

导出过程只读取书籍，原始导入文件和应用内书籍保持不变。保存位置由用户选择，也可以取消本次导出。

## 文字阅读

点击正文显示或收起阅读菜单。目录用于选择章节，搜索用于查找书内文字，书签用于回到标记过的位置，设置用于调整主题、字体、字号、行高和阅读模式。

除了系统字体，还可以选择内置的宋体和楷体。两种内置字体都随应用安装，不需要联网下载。

楷体字库覆盖了全部常用简体汉字，以及常用的中文标点。遇到繁体或生僻字时，这些字会改用系统字体显示。导入 .ttf 或 .otf 字体以后，也可以在这里选用。

选用楷体时，粗细的三档会依次加重。其中最粗的一档，相当于旧版本里的中等粗细。

正文两端对齐：自动换行的每一行都排到左右页边，段落最后一行保持自然长度，段首缩进始终是两个字宽。落在行末的逗号、句号、后引号和后括号只占半个字宽，所在字体带有半宽标点时，换行后出现在行首的前引号和前括号也收成半宽。英文单词和数字内部的字距保持原样，多出的宽度分到汉字之间和单词之间。滚动模式下，快速滑入的长章节会在滚动停下后完成对齐。

主题有系统、浅色、暖色、深色和纯黑五种。纯黑主题的背景完全为黑色，在 OLED 屏幕上这部分像素不发光，阅读时更省电。

菜单展开时，顶栏和底栏的内侧边缘落在行与行之间，三种阅读模式都会自动对齐。被边缘切到的那一行由菜单整行遮住，露在外面的正文都是完整的行。滚动模式下拖动正文时，菜单边缘会在滚动停下后重新对齐。

阅读背景延伸到屏幕边缘，正文避开摄像头区域。横屏时摄像头或导航栏通常只在一侧，正文左右两边都按较宽的一侧留出距离，保持在屏幕中间。菜单展开时显示状态栏，收起时隐藏顶部状态图标，底部系统手势导航保持可用。打开目录、搜索或编辑器时，键盘不会改变背后正文的分页高度。

目录顶部可以按章节名、卷名或章节序号检索，支持全角数字。搜索卷名的时候，结果会列出该卷的全部章节。

目录面板打开时会直接展开到最大高度，无需再向上拖动。在列表里面，当前章节默认排在第一行。如果当前章节位于展开的分卷里，它会紧贴在固定的卷名下方。

点击“回到当前章”会清除搜索并展开当前分卷，再把当前章节移回第一行。对于很长的目录，列表只会按需构建可见的行。

为了显示完整的章节标题，目录使用了较小的字号。遇到特别长的标题，列表会在行尾用省略号收起。

新导入的 EPUB 2 和 EPUB 3 可以识别同一正文文件中的多个目录位置。若要补全旧书的目录或资源，请用原始 EPUB 重新导入。原有副本及其阅读进度和书签会保留。

- 分章：上下滚动当前章节，左右滑动切换章节。
- 滚动：各章节排列为连续的纵向阅读内容。
- 仿真：按页阅读，可选择仿真翻页或平滑翻页效果。

选择仿真翻页效果之后，页角会跟着手指从页边卷起来。从屏幕上部三分之一的位置向左拖动，可以掀起右上角。起手位置落在下部三分之一的时候，被掀起的会是右下角。

在中间一段起手的时候，整页会沿一条竖直折痕翻起来。卷起的页角先从页边追上手指，随后停留在指尖下方。透过卷起的纸背，还能看到本页文字的淡淡镜像。

向右拖动的时候，上一页会沿竖直折痕从左侧卷回来。松开手指之后，拖过足够距离的页面会继续翻过去。只要滑动速度足够快，短促的轻扫也能完成翻页。

拖动距离太短的时候，页角会落回原来的页边。翻到一半想要放弃的话，向回快速一甩就能让页面落回原处。平滑翻页效果保持左右平移，不会出现卷页。

松开手指之后，页面会接着手指的速度滑向终点：甩得越快，落定越快，全程不会越过页边再弹回。已经翻到全书第一页或最后一页时，页面仍会跟着手指移动一小段。页面越往外拉越吃力，松开手指后会自动回到原位。

系统省电模式开启期间，仿真翻页会暂时改用平滑翻页，设置面板的翻页效果下方会显示提示；关闭省电模式后自动恢复。

翻页、滚动以及开合书本的过程中，应用会请求屏幕当前分辨率下的最高刷新率，画面停下后随即撤回，让屏幕回到空闲刷新率。系统设置里的刷新率上限和省电模式仍然优先。

## 划线、笔记、金句卡片与书签

阅读菜单展开后，顶栏右侧的书签按钮记下当前页第一整行的位置，再点一次取消。底部的“笔记”打开综合面板，分“全部 / 批注 / 书签”三栏管理当前书籍的所有记录，支持按颜色与分类筛选、正文排序或最新时间排序、关键词检索以及一键导出整本 Markdown 笔记文件。

长按正文选中一段文字后，选区悬浮工具栏上方直接提供五种配色（琥珀、陶红、松绿、靛青、丁香）与四种样式（荧光、直线、波浪、虚线），点选即可直接内联高亮，也可以点击“写笔记”选择分类（摘录、想法、金句、疑问、批注）与自定义标签，或点击“金句卡”生成高清长图保存。已标注的正文直接绘制荧光/下划线与批注圆点提示（不改变正文排版与仿真翻页页高），轻触正文上的任意划线即可弹出快速面板原地改色、换线型、复制、生成金句卡或补写想法。

从书架全局设置（普通模式进入常规“读书笔记”，隐私模式进入隔离的“隐私笔记本”）还可跨书集中检索和浏览全部高亮与想法，并一键跳转原文或生成“宣纸书笺 / 墨韵深夜 / 素雅留白 / 典藏色卡”四种模版的 `.png` 金句长图。PDF 也已接入统一富文本笔记体系：除支持在笔记面板直接新增或编辑外，在“选择本页文字”中选中文字同样可以直接点击“写笔记”。笔记与书签跟随章节和段落锚点定位，换字体、改边距或切换阅读模式后仍准确附着于原句。

## 选择文字

长按文字形成选区，拖动选择手柄调整范围。自定义悬浮工具栏整合五色高亮、四类划线样式、“写笔记”、“金句卡”以及复制、翻译、网页搜索、分享与全选操作。

分章和滚动模式支持边缘拖选：把拖选位置或手柄移到顶部、底部附近，正文会自动滚动；松手或移回中间时停止。分章模式的范围限于当前章，滚动模式可以跨章。松手后上下滑动正文会保留原来的选中文字，滚动停止后显示选择菜单；拖动手柄可以继续调整选区。

仿真模式的选择范围限于当前页。翻译和网页搜索会让你选择用于接收文字的外部应用。

## EPUB 的注释与内部链接

EPUB 正文里的脚注编号和内部引用会以强调色显示并带下划线，可以直接点击。目标是一段短注释时就地弹出，读完关闭即可，阅读位置不变；面板里的“跳转到该位置”会真正翻过去。目标较长时直接跳转。

指向站外网址的链接保持普通文字，不会点开浏览器。

书内目录使用两列表格时，条目和页码会分行对应，点击标题可跳到正文。窄屏空间不足时，标题和页码仍在同一条目内显示。

## 编辑章节

在分章模式的阅读菜单中打开全屏编辑器，章节标题输入框直接位于顶栏，右侧保存按钮位置不变。编辑器打开时正文框不会自动聚焦，键盘保持收起；正文首行对应你在阅读页看到的第一整行，顶部被裁掉一半的那行会自动跳过。顶部按钮位于安全区域内，键盘展开时正文编辑区域相应缩小。修改保存在 ReadVibe 的私有副本中。

顶栏的查找替换按钮展开查找面板，只在当前章正文内匹配。命中会直接着色，计数显示当前序号与总数，可以逐个跳转、替换当前一处或全部替换；单次展开最多处理 500 处匹配，超出时提示可再次替换剩余部分。

正文编辑统一使用全角空格（U+3000）：按一次空格键占一个汉字宽度，段首缩进两字就按两次。打开编辑器时，已有的半角空格、制表符和其他横向空白按一字符一格转换，保留原来的数量和换行；粘贴、查找和替换遵循同一规则。中文输入法选词期间不转换，确认输入后再生效。仅打开或关闭编辑器不会写入书籍；保存编辑后，当前章节的正文使用统一的空格。

正文底栏提供撤销和重做，包括输入、粘贴和查找替换造成的正文修改。历史仅在本次编辑器会话内保留，保存仍由右上角按钮确认。

富文本章节以纯文本方式编辑，保存前会提示格式转换。关闭含有未保存修改的编辑器时，会询问是否放弃修改。

## PDF 阅读

左右翻页，双指缩放查看页面。底部提供进度滑杆、页码跳转、书签和笔记入口；顶部提供大纲、搜索和工具菜单。

工具菜单可调整显示主题，选择本页文字，对扫描件进行文字识别或全文搜索。PDF 的可搜索文字和大纲取决于文件本身；扫描件可以使用 OCR。受密码保护的 PDF 在导入时需要提供打开密码。

PDF 页面按固定版式绘制，页面本身无法直接划选。“选择本页文字”把当前页的文字单独列出，可以长按选中其中一段复制或分享，也可以一次复制整页。原生文字层优先使用，没有文字层的扫描页会自动改用识别结果，面板顶部标明文字来源。

页面加载失败时可以选择“重新加载此页”，应用会重建该 PDF 的临时渲染缓存，保留源文件和笔记。关闭 OCR 搜索后，当前正在处理的页面结束即停止后续扫描。切到后台时保存当前页码，返回后恢复阅读系统栏。

## 存储空间

全局设置的“存储空间”列出书籍正文、EPUB 图片与字体、Word 图片、PDF 副本、导入字体各自的占用，以及可清理的缓存总量。

“清理缓存”只删除可以重新生成的数据：PDF 渲染出的页面图片、扫描件的识别结果和未完成的安装包。书籍、阅读进度、章节编辑和书签不受影响，重新打开 PDF 会自动重新渲染。

书架空闲时分批检查本地资源。进入阅读、导入、导出或后台时，维护在当前书检查结束后暂停；深度内容校验在工作线程执行。

## 更新

全局设置提供手动检查更新和自动检查开关。开启自动检查后，应用每 24 小时检查一次新版本，间隔从上次成功检查的时间算起。到点时如果正在读书，提示会等你回到书架再弹出。网络不通时，应用会在一小时后再试。检查会同时询问几条国内镜像线路和 GitHub，最先答复的线路决定结果，其余线路再等不到一秒，以免旧缓存漏掉新版本。发现新版本后，弹窗列出安装包体积与自动按常见 Markdown 规则排版的更新说明（支持标题层级、重点加粗、行内代码、多级列表、任务项、引用提示、表格及底部的 SHA-256 校验区，去除原始 `##`/`**` 等标记符号）。点击下载以后，应用会优先沿用上一次成功下载使用的线路直接取包（首次下载优先选用主国内镜像），不提前测速；只有当这条线路不可用，或者下载速率持续过低时，才会在三秒内测速其余备用线路并切换到最快的一条。国内镜像优先，只有 GitHub 直连快出一半以上时才会改走直连，已经下好的部分以及测速时取到的有效片段都会直接接着用，不会从头再来。下载中显示线路、百分比与实时速率，可随时取消；下载完成并通过体积、格式与 SHA-256 校验后，应用会记住本次使用的线路并调起系统安装程序。首次安装需要在系统设置里允许 ReadVibe 安装应用，授权后回到弹窗直接安装，无需重新下载。
