# ReadVibe — 本地离线小说阅读器

ReadVibe 是使用 Flutter 构建的 Android 本地小说阅读器。应用支持导入 TXT、EPUB、DOCX 和 DOC，并在设备本地完成解析、分章、排版、阅读设置、全文与逐章字数统计和进度保存。

## 当前功能

### 本地书架

- 导入 `.txt`、`.epub`、`.docx` 与 `.doc`。
- 手机书架固定每行显示三本，书卡标题、格式标签和元信息按三列宽度紧凑排版。
- 书卡显示作者、章节数、阅读比例和全文字数。
- 字数尚未完成时显示“全文字数统计中…”，书籍仍可立即打开。
- 全文字数按书排队，在后台 isolate 中统计章节标题和正文的非空白 Unicode 字符。
- 长按书卡固定打开“修改名称 / 移动 / 删除”三个选项；修改名称为完整主操作，移动和删除为图标加小文字的紧凑按钮。
- 选择“移动”后进入专门的三列书架整理态；拖起书卡会抬升并增加阴影，原位保留半透明占位，相邻书卡以弹性位移动画让位，靠近屏幕边缘时自动滚动。
- 松手后书卡回弹到网格并在本地持久化新顺序；返回键、左上角关闭或“完成”退出整理态。改名只更新本地元数据。
- 整理态顶部使用紧凑的 20 px 标题和单行拖动提示，书卡紧接提示下方显示，不保留大块顶部空白。

### TXT、EPUB 与 Word 文档

- TXT 支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM 和常见 GBK 文本。
- 兼容 CR、LF、CRLF、NEL、Unicode 行分隔符和段落分隔符。
- 识别常见中文、英文和 Markdown 章节标题。
- 纯卷标题保存为目录结构，不生成空白阅读页。
- EPUB 按 spine 顺序提取为适合小说阅读的纯文本内容。
- DOCX 在 Dart isolate 中解压并读取 `word/document.xml`；表格与段落按文档顺序转为纯文本后复用现有分章器。
- 旧版 DOC 通过 Android 端 Apache POI HWPF 在单独工作线程本地提取文本，加密或损坏文档会明确拒绝。
- 解析、解压和较大的 JSON 编解码在后台 isolate 中运行。

### 阅读与进度

| 手势 | 行为 |
|---|---|
| 单击正文 | 显示或关闭阅读菜单 |
| 双击正文 | 不选中文本，不显示选择工具栏 |
| 长按正文 | 选择文本，并显示复制、分享、全选、翻译、搜索 |
| 上下滑动 | 分章模式滚动当前章；滚动模式连续阅读全文 |
| 左右滑动 | 分章模式切章；仿真模式逐页翻阅 |
| 点击目录项 | 从章首打开指定章节 |

- 三种模式共用每章独立的滚动像素和归一化阅读比例。
- 切章前先保存离章状态，相邻章节在预览阶段恢复自身位置。
- 切换阅读模式、菜单、主题、字体和排版设置后继续保持当前阅读位置。
- 翻页提交后沿用预览页的真实位置，不先显示章首再跳转。
- 顶部阅读菜单显示当前章节序号和章节名，并随当前章节变化；不再占用该位置重复显示书名。

### 目录

- 有明确卷标题时显示卷与章节两级目录。
- 没有卷标题时显示单层章节列表。
- 简介、前言、序言等卷外内容作为顶部一级项。
- 卷默认展开，折叠状态按书保存。
- 标题区显示章节总数和全文字数；后台统计完成后原地刷新。
- 每个可读章节最右侧显示该章正文的非空白 Unicode 字数；未完成时先显示“统计中…”，结果到达后原地刷新并持久化，后续开书直接复用。

### 三种阅读模式

- “分章”是默认模式：单章纵向滚动，全文保持分章，左右平移切换相邻章节。
- “仿真”锁定纵向滚动，按照扣除纸页留白后的正文视口高度逐页推进；选中后在下方展开“仿真翻页 / 平滑翻页”二级选项。
- “滚动”把全部章节放入同一条纵向内容流，滚过章节边界时自动更新当前章节及该章进度。
- 仿真页正文上下通常各保留约一行、最多接近一行半的动态留白，左上角以小字显示章节序号、总章数和章节名。
- 仿真正文区只容纳完整行数，章节标题、正文和段间距统一到同一行高网格；保存位置会先吸附到最近完整行。
- 仿真翻页从当前完整行起点移动一个真实正文视口，不会在页面顶部或底部从字的中间截断。
- 二级选项默认“仿真翻页”，选择结果保存到本地设置；切换效果不改变当前章节或局部进度。
- “仿真翻页”使用大面积斜向纸页裁切、曲面折痕、阴影和纸背渲染；仿真模式以原始指针位移跟踪翻页，不受正文选区手势竞争影响。快照未就绪时先显示同一套主题纸背，不会自动回退成平滑平移。
- 左滑前翻时，当前页的右边缘沿随手指落点变化的斜折线卷向左侧；反射后的自由边形成可见的大块纸背，下一页从纸张下方显露，页面本体不做水平平移。
- 右滑回到上一页时，当前页保持在底层，上一页使用独立的入页几何从左侧逐步铺开并盖住当前页；上一页正面与领先纸背共同覆盖屏幕，这是实体盖页路径，不是前翻动画的反向播放。
- 仿真纸背来自正在运动的实际纸页：前翻捕获当前页，后翻捕获上一页。当前页在稳定阅读状态下异步预取，上一页在目标预览完成布局后异步捕获；手指按下、拖动和回弹不做同步整页截图。快照围绕当前斜折线反射，页眉、标题和正文以透纸字迹显示在反面。
- “平滑翻页”使用当前页与目标页的水平跟手平移，不捕获纸背快照；按屏分页、完整行、页眉和进度保存与仿真翻页共用。
- 分章模式不再提供仿真翻页开关，避免章节平移被误认为仿真翻书。

### 阅读设置

- 字号：16、18、20、22、24，默认 20。
- 行距：1.4、1.6、1.8、2.0、2.2。
- 字重：细、中、粗。内置宋体的“中”使用原“粗”的加粗效果，“粗”再增加同色锐利加厚，三档保持可辨。
- 页边距：窄、中、宽。
- 段落间距：不空行、空一行，默认不空行。
- 阅读模式：分章、仿真、滚动，默认分章。模式说明小字以纵向滚入、滚出连续切换，全程不做淡入淡出。
- 仿真模式翻页效果：仿真翻页、平滑翻页，默认仿真翻页；仅选中仿真模式时显示。
- 主题：跟随系统、浅色、暖色、深色。
- 字体：系统字体、内置宋体、用户导入的 `.ttf` / `.otf`。
- 阅读设置底部面板打开由 360 ms 小幅缩短到 330 ms，关闭由 240 ms 缩短到 220 ms；书架设置侧栏为 330 ms。

### 主题安全转场

- 开书与关书使用同一条 680 ms 正反时间线。
- 当前阅读主题同步用于阅读页、过渡纸面、书架底层和系统栏。
- 关闭书籍时，转场资源保留到反向动画完全结束。
- 深色主题下不会主动插入浅色纸面作为过渡背景。

## 隐私与数据

- 书籍正文、书架元数据、设置、字体和阅读进度保存在应用本地目录。
- Android 系统云备份关闭。
- 只有用户主动点击“翻译”或“搜索”后，选中文字才会发送到所选外部应用。Android 先使用系统 `PackageManager` 获取真实可处理目标，ReadVibe 再在前端将翻译筛选为白名单 AI，将搜索筛选为 edge、chrome 和系统浏览器；原生层按系统返回的显式组件启动。翻译内容自动包装为 `翻译如下内容：“所选文字”`。
- 翻译和搜索选择面板都改为可左右滑动的横向目标卡。翻译卡使用从各应用官方 Google Play 页面取得的本地 WebP 图标，不再显示通用机器人或单选圆点；搜索卡不使用图标，通过品牌字标、描边和底部强调线表达选中状态。两个面板均可勾选“记住并默认打开”；全局设置可清除两个默认目标并重新选择。
- 删除书籍时同步清理正文、进度和目录展开状态。
