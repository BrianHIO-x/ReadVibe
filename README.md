# ReadVibe

ReadVibe 是一款面向 Android 的本地阅读器，支持导入 TXT、EPUB、MOBI、AZW、AZW3、PDF、DOCX 和 DOC。书架提供搜索、筛选、书籍信息修改、拖动排序和文件导出，阅读进度与个人设置保存在设备上。

文字阅读提供分章、滚动和仿真三种模式，可以使用目录、书内搜索、文本选择及字体排版设置。分章模式还可以编辑当前章节的标题和正文。PDF 使用独立阅读界面，提供缩放、跳页、搜索、大纲、书签、笔记和扫描件文字识别。

## 开始使用

1. 从 [GitHub 发布页面](https://github.com/BrianHIO-x/ReadVibe/releases) 获取 Android 安装包。当前 Android 工程最低支持 Android 8.0。
2. 打开应用，点击书架的导入按钮选择本地文件；也可以在文件管理器中使用 ReadVibe 打开受支持的文件。
3. 点击书卡进入阅读。文字阅读页的菜单中可以打开目录、搜索和设置，分章模式提供编辑入口。长按书卡可以修改信息、调整顺序或删除书籍。
4. 长按书卡选择“导出文件”，通过系统界面选择保存位置。文字书导出包含已保存修改的 UTF-8 TXT，PDF 导出当前副本。

详细操作见 [阅读与书架操作](docs/UI_OPTIMIZATION.md)。

## 隐私保护

书籍正文、阅读进度、章节编辑和个人设置保存在本机。书籍解析、正文搜索和 PDF 文字识别在设备上处理；章节编辑修改应用私有副本，原始导入文件保持不变。导出的文件写入你在系统保存界面选择的位置。

自动检查更新默认关闭。手动检查或开启自动检查时，应用会访问 GitHub；下载入口打开发布页面。使用分享、翻译或网页搜索时，所选文字会交给你选择的第三方应用或浏览器。
