# ReadVibe

ReadVibe 是一款面向 Android 的本地离线阅读器，支持导入 TXT、EPUB、MOBI、AZW、AZW3、PDF、DOCX 和 DOC。小说与文档共用分章、滚动和仿真三种阅读模式，并提供目录、全文搜索、文本选择、字体与排版设置；EPUB 可保留封面、图片、常用样式和未加密 TTF/OTF 内嵌字体，DOCX 可保留标题样式、行内强调、表格、脚注和图片。书架支持按书名、作者和格式搜索，可按最近阅读、未读或格式筛选，书名与作者也可以手动修正。

当前公开版本为 `v0.6.7`，适用于 Android 8.0（API 26）及以上的 `arm64-v8a` 设备。PDF 保持原始固定版式，支持缩放、显示主题、跳页、文字层搜索、大纲、书签、内嵌文字批注、密码导入和中文离线 OCR；书架顺序、阅读进度、PDF 状态和个人设置均保存在本机。`v0.6.7` 首次使用正式发布证书，旧 debug 证书安装版无法被新证书覆盖，必须卸载后重新安装，旧版应用私有数据无法自动迁移，请保留原始书籍文件。

## 开始使用

1. 下载并安装 [ReadVibe v0.6.7 Android 安装包](https://github.com/BrianHIO-x/ReadVibe/releases/download/v0.6.7/ReadVibe-Android-v0.6.7-arm64-v8a.apk)。首次安装时，请按 Android 系统提示确认安装。
2. 打开 ReadVibe，点击书架上的导入按钮，从设备中选择 TXT、EPUB、MOBI/AZW、PDF 或 Word 文件；也可以在 Android 文件管理器中选择受支持文件并使用 ReadVibe 打开。受密码保护的 PDF 会在导入时询问打开密码。
3. 点击书卡开始阅读；小说菜单提供目录、全文搜索和排版设置，PDF 工具提供显示主题、文字层搜索、扫描件 OCR 与批注。长按书卡可以修改书名和作者、调整顺序或删除书籍。全局设置中可以检查更新和查看开源许可。

## 隐私保护

ReadVibe 不需要账号，也不提供云同步。书籍解析、正文搜索、字数统计、PDF 搜索/大纲、密码解锁、批注和 OCR 均在设备本地完成；中文 OCR 模型随应用打包，页面图像和书籍正文不会上传，EPUB 远程资源也不会加载。PDF 密码只在本次导入时使用，应用保存的是设备内已解锁副本，不保存密码。从文件管理器打开的文件会先复制到私有缓存，再经过相同的本地校验。自动检查更新默认关闭；发现新版本后只打开 GitHub Releases，下载与安装由浏览器和系统处理。只有主动使用翻译、分享或网页搜索时，所选文字才会交给用户明确选择的第三方应用或浏览器。
