# ReadVibe

ReadVibe 是一款面向 Android 的本地离线阅读器，支持导入 TXT、EPUB、PDF、DOCX 和 DOC 文件。TXT、EPUB、DOCX 与 DOC 共用分章、滚动和仿真三种阅读模式，并提供目录、全文搜索、文本选择、字体与排版设置；PDF 按原始版式逐页阅读，支持跳页、阅读进度和本地书签。书架可以按书名搜索，并按最近阅读、未读或文件格式筛选。

当前公开版本为 `v0.6.7`，适用于 Android 8.0（API 26）及以上的 `arm64-v8a` 设备。书架顺序、阅读进度、PDF 书签/笔记和个人设置都会自动保存在本机，重新打开书籍后可以继续阅读。`v0.6.7` 首次切换到正式发布证书，旧 debug 证书版本无法覆盖安装，升级前需要自行备份书籍并卸载旧版。

## 开始使用

1. 下载并安装 [ReadVibe v0.6.7 Android 安装包](https://github.com/BrianHIO-x/ReadVibe/releases/download/v0.6.7/ReadVibe-Android-v0.6.7-arm64-v8a.apk)。首次安装时，请按 Android 系统提示确认安装。
2. 打开 ReadVibe，点击书架上的导入按钮，从设备中选择 TXT、EPUB、PDF、DOCX 或 DOC 文件；也可以在 Android 文件管理器中选择受支持文件并使用 ReadVibe 打开。
3. 点击书卡开始阅读；在阅读页打开菜单后，可以使用目录、全文搜索和阅读设置。长按书卡可以修改名称、调整顺序或删除书籍。全局设置中可以手动检查更新，也可以自行开启自动检查。

## 隐私保护

ReadVibe 不需要账号，也不提供云同步。书籍解析、正文搜索、字数统计、PDF 搜索/大纲、书签、笔记和阅读记录均在设备本地完成，书籍正文不会上传；EPUB 中的远程资源也不会加载。从文件管理器打开的文件会先复制到应用私有缓存，再经过与手动导入相同的本地校验。自动检查更新默认关闭；检查到新版本后只打开 GitHub Releases，下载与安装交给浏览器和系统处理，因此 ReadVibe 不再申请安装 APK 权限。只有当你主动使用翻译、分享或网页搜索时，所选文字才会交给你明确选择的第三方应用或浏览器处理。
