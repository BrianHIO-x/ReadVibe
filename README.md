# ReadVibe

ReadVibe 是一款面向 Android 的本地阅读器/小说软件，支持导入 TXT、EPUB、MOBI、AZW、AZW3、PDF、DOCX 和 DOC。书架提供多选导入、自定义分组、多选批量管理、搜索、筛选、书籍信息修改、拖动排序、文件导出与本地 `.zip` 备份恢复，阅读进度与个人设置保存在设备上。

文字阅读提供分章、滚动和仿真三种模式，可以使用目录、书内搜索、书签笔记、文本选择及字体排版设置。任意位置都可以加书签，选中一段文字可以直接写笔记。EPUB 的脚注和内部引用可以点击，短注释就地展开。分章模式还可以编辑当前章节的标题和正文，编辑器支持在当前章内查找替换。PDF 使用独立阅读界面，提供缩放、跳页、搜索、大纲、书签、笔记、本页文字选择和扫描件文字识别。

## 开始使用

1. 从 [GitHub 发布页面](https://github.com/BrianHIO-x/ReadVibe/releases) 获取 Android 安装包。当前 Android 工程最低支持 Android 8.0。
2. 打开应用，点击书架的导入按钮选择本地文件（支持一次多选导入多本书）；也可以在文件管理器中使用 ReadVibe 打开受支持的文件。
3. 点击书卡进入阅读。文字阅读页的菜单中可以打开目录、搜索、书签和设置，顶栏右侧的按钮记下当前位置，分章模式提供编辑入口。长按书卡可以修改信息、设置分组、调整顺序或删除书籍，也可在右上菜单进入多选模式批量分组、移入隐私书架或删除。
4. 长按书卡选择“导出文件”，通过系统界面选择保存位置。文字书导出包含已保存修改的 UTF-8 TXT，PDF 导出当前副本。全局设置还提供“本地备份与恢复”，可将书架、阅读进度、书签笔记与设置打包导出为 `.zip` 并合并恢复。

详细操作见 [阅读与书架操作](docs/USAGE.md)。

书架按屏幕宽度决定每行放几本，横屏和平板会自动增加列数。同一个文件可以重复导入，第二本起书名自动编号，两本书的正文、进度和笔记互不影响。全局设置里可以看到各类数据的占用并单独清理缓存。

隐私书架可以收起不想公开的书籍，进入时需要验证密码、指纹或人脸；打开隐私书架或阅读隐私书籍时，应用会自动禁止系统截屏、录屏及多任务缩略图展示。

## 隐私保护

书籍正文、阅读进度、章节编辑和个人设置保存在本机。隐私书架的密码只以加盐摘要保存在本机，不会离开设备；处于隐私书架或阅读隐私书籍期间，系统安全窗口标志会阻止截屏、录屏及最近任务缩略图截取内容，退出或锁上后自动解除。书籍解析、正文搜索和 PDF 文字识别在设备上处理；章节编辑修改应用私有副本，原始导入文件保持不变。导出的文件及本地 `.zip` 备份写入你在系统保存界面选择的位置，本地备份不会导出隐私锁屏密码或生物验证配置。

自动检查更新默认关闭。手动检查或开启自动检查时，应用会同时询问国内镜像线路和 GitHub 发布接口，优先采用国内镜像的结果。确认下载后，安装包由应用自己取回并校验体积与 SHA-256，再交给系统安装程序，整个过程不离开应用。使用分享、翻译或网页搜索时，所选文字会交给你选择的第三方应用或浏览器。
