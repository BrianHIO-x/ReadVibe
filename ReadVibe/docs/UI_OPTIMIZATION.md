## 二、交互目标

- 单击显示或关闭菜单时，正文保持当前位置。
- 调整主题、字号、行距、字重、字体、页边距和段落间距后，正文保持阅读比例。
- 每章保存自己的滚动位置，往返切章不串写。
- 分章、滚动和仿真模式之间切换时保持当前章节与局部比例。
- 滚动模式跨越章节边界时连续显示内容并更新当前章节。
- 仿真模式在同一章内部按屏翻页，选中后显示“仿真翻页 / 平滑翻页”二级选项，默认仿真翻页。
- 选择仿真翻页时无条件使用卷页几何；快照状态只影响纸背文字，不影响当前页裁切、折痕、阴影或目标页显露。
- 选择平滑翻页时使用当前页与目标页跟手平移，但仍共用仿真模式的完整行分页、页眉、预览页和进度提交。
- 仿真每一页的正文上下保留约一行到一行半的紧凑留白，左上角显示小号章节信息，页面边缘只落在完整行之间。
- 相邻章节第一次进入翻页画面时已经位于保存位置。
- 翻页动画完成后不再发生二次位置跳转。
- 左滑前翻由当前页离开，右滑后翻由上一页从左侧盖回，两者不共用反向动画层级。
- 仿书纸背显示实际运动纸页的真实镜像文字：前翻对应当前页，后翻对应上一页。
- 双击不选择文本，长按只显示五项指定操作。
- 全文与逐章字数统计不阻塞书架、开书或目录操作。
- 阅读菜单顶部显示当前章节序号和章节名，不再显示书名，并与三种模式的活动章节保持同步。
- 深色主题的开书与关书转场不插入浅色中间帧。
- 书架在手机宽度下每行稳定显示三本书，书卡文字、标签和进度条不溢出。
- 阅读模式选项按“分章 / 仿真 / 滚动”排列；说明小字用不变透明度的纵向滚动方式连续切换。
- 内置宋体的“细 / 中 / 粗”三档可视区分，“中”使用原“粗”的加粗效果。
- 书架长按固定进入“修改名称 / 移动 / 删除”三项菜单；选择移动后才进入独立整理态，并在落位后持久化顺序。
- DOCX 和 DOC 导入不阻塞 UI，并复用现有分章、目录和字数统计模型。
- 阅读设置底部面板与书架设置侧栏只小幅缩短时长，不改变原曲线和状态应用时序。

## 三、解析与排版

### TXT

- 支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM 和常见 GBK。
- 支持 CR、LF、CRLF、NEL、Unicode 行分隔符和段落分隔符。
- 识别常见中文章节、回目、卷、节、英文 `Chapter` 和 Markdown 标题外壳。
- 标题显示前清理前导半角与全角空格。
- 普通句子不会因为包含“卷”或“节”就被识别为标题。
- 首个章节前的有效正文保留为开篇内容。
- 没有正文的连续标题不生成空白阅读章节。
- 纯卷标题保存到后续章节的 `volumeTitle`，用于目录分组。
- 大文件读取、解码、分章和 JSON 编解码在 isolate 中执行。

### 段落

- 存储层用单换行表示自然段。
- 显示层清理正文原始前导空格，再添加两格全角首行缩进。
- 段落间距默认“不空行”。
- 用户可切换为“空一行”，该设置只影响显示布局。

### EPUB

- 在 isolate 中解压和解析。
- 从 `container.xml` 定位 OPF，读取 metadata、manifest 与 spine。
- 按线性 spine 顺序处理 XHTML。
- 跳过非线性、空白、脚本和样式内容。
- 块级 HTML 转换为小说段落换行。
- 归档条目数、单项大小和总解压体积均有保护边界。

### DOCX 与 DOC

- DOCX 在 Dart isolate 中解压，读取 `word/document.xml` 的段落、表格文本、换行和制表符。
- DOCX 限制原文件、归档条目、总解压体积和主 XML 体积，拒绝 ZIP 异常膨胀、加密或损坏数据。
- 二进制 DOC 使用 Apache POI 5.5.1 `HWPFDocument` / `WordExtractor`，在 Android 单线程 executor 中提取文本，结果再交给 isolate 分章。
- 两种 Word 格式都转为纯文本小说模型，不保留图片、复杂样式、批注或修订版式。

## 四、目录显示模型

目录先建立 `_TocDirectory` 显示模型，再交给列表按需渲染：

- 至少一个章节具有明确卷名时，建立卷与章节两级结构。
- 完全没有卷信息时，直接显示单层章节列表。
- 卷标题是一级折叠项，所属章节是缩进的二级可读项。
- 简介、作品简介、作者简介、前言、序言、序章、楔子、引子和开篇等卷外内容位于顶部。
- 后记、尾声、附录和番外等内容保持独立一级项。
- 含正文的卷首页作为卷内可读章节显示。
- 卷初次显示为展开状态。
- 折叠集合以书籍 ID 为作用域保存到 `SharedPreferences`。
- 当前章节位于折叠卷时，目录定位到卷标题并保留折叠状态。
- 删除书籍时同步清理目录折叠数据。
- 标题区通过 `ValueListenable<int?>` 显示章节总数和全文字数。
- 每个 `_TocChapterRow` 的最右侧通过 `ValueListenable<List<int>?>` 显示对应章节正文的非空白 Unicode 字数。
- 章节字数未就绪时显示“统计中…”，完成后保持目录打开并原地刷新；数字使用千位分隔和等宽数字特性右对齐。
- 卷标题不是可读章节，右侧继续显示卷内项目数，不显示章节字数。

## 五、菜单与正文位置

### 稳定组件层级

三种模式的正文始终位于稳定的 `SelectionArea` 内。菜单显隐不会把活动阅读视图移动到另一套组件树，因此不会重新创建活动 `ScrollPosition`。

顶部菜单以 48 px 控件高度容纳两行信息：第一行是“当前章节 当前序号/总章数”，第二行是清理显示格式后的章节名。长标题单行省略；分章切换、滚动跨章和仿真提交通过同一个 `_chapterIndex` 驱动刷新。

### 单击识别

阅读页根据原始指针的按下位置、移动距离、持续时间和抬起位置判断短按：

- 有效单击切换菜单；
- 移动超过阈值后不再判定为单击；
- 纵向滚动、横向翻章和长按选择不触发菜单切换。

菜单变化前立即记录当前像素和阅读比例。布局完成后再次检查同一控制器，如果外层安全区变化造成偏移，则恢复到安全像素。

### 系统栏

- 阅读内容接管后隐藏顶部状态栏。
- 底部手势导航区域保留。
- 打开阅读菜单时显示状态栏，关闭后恢复沉浸状态。
- 阅读页保存稳定顶部安全区，系统栏切换不推动正文。
- 系统栏颜色和图标亮度由当前 `ReaderThemeColors` 统一生成。

## 六、文本选择

### 双击

- `SelectionArea` 子树中的双击识别器接管第二次点击。
- 阅读页记录短按时间与位置；确认双击时清理可能提前建立的选区。
- 长按发生在双击窗口之外，仍可建立选区并拖动手柄。

### 长按菜单

`SelectionArea.contextMenuBuilder` 只构建以下五项：

1. 复制
2. 分享
3. 全选
4. 翻译
5. 搜索

复制、分享和全选复用平台 `ContextMenuButtonItem` 的回调。翻译和搜索由 `SystemTextActionService` 通过 MethodChannel 读取 Android 系统的真实 Intent 解析结果：

- Android 用 `PackageManager.queryIntentActivities()` 分别查询 `ACTION_SEND`、`ACTION_PROCESS_TEXT` 和 `ACTION_TRANSLATE`；Flutter 再将实际解析结果筛选为 DeepSeek、ChatGPT、Gemini、Claude、Microsoft Copilot 和 Perplexity，前端不显示其他翻译、文本处理或分享目标。
- 发送给 AI 的文字由 Android 端固定包装为 `翻译如下内容：“所选文字”`；原生层使用系统返回的真实包名、Activity 和 Intent 类型构造显式 Intent，启动前再次核对 AI 包名白名单和可解析性。
- Android 用 `ACTION_VIEW` 查询真实网页处理器；Flutter 固定产生 `edge / chrome / 系统浏览器` 三行，Edge 或 Chrome 未安装时保留禁用行。Edge 和 Chrome 使用系统返回的显式组件，系统浏览器使用未限定包名的原生 `ACTION_VIEW` Intent。
- 翻译目标放入高度 120 的横向 `ListView`，每张卡宽 104，选中时放大、显示强调描边与轻阴影。六个 AI 应用图标来自对应官方 Google Play 页面，以 192×192 WebP 存放于 `assets/images/ai/`；通用机器人图标和单选圆点不再绘制。
- 搜索目标同样放入高度 120 的横向 `ListView`，每张卡宽 112；不包含浏览器位图或 Material 图标，只使用 `SEARCH WITH`、目标字标、选中描边和宽度动画强调线。
- 选择面板使用当前阅读主题配色并提供“记住并默认打开”。默认目标分别保存在轻量设置中，下次直接跳转；目标失效时清除默认并恢复选择面板。
- 书架全局设置提供“重新选择默认应用”，一次清除翻译和搜索默认值。

只有用户主动点击翻译或搜索后，选中文字才会交给外部应用。

## 七、阅读进度状态

### 保存字段

每本书保存：

- 当前章节索引；
- 当前滚动像素；
- 当前归一化阅读比例；
- 每章独立像素映射；
- 每章独立比例映射；
- 最后阅读时间。

反序列化时过滤非有限数值、负数、越界比例和无效章节索引。

### 当前章节

- 活动模式把当前章节局部像素和比例更新到内存快照。
- 本地进度保存使用 500 ms 防抖。
- 保存任务串行执行，后续状态不会被先前异步写入覆盖。
- 页面关闭、应用进入后台、开始横向翻页和连续滚动跨章时主动排队保存。
- 控制器断开后使用最后一个有效快照，不回退为零值。

### 离章顺序

横向手势开始时锁定来源章节索引、像素和比例。提交跨章翻页时先保存来源章节，再切换活动章节与控制器，最后保存目标章节状态；滚动模式在章节标题越过视口顶部时执行同样的来源章与目标章记录顺序。

### 设置重排

字体、字号、行距、字重、页边距、段落间距和阅读模式会改变正文结构。设置应用前保存当前章节的局部比例，重排后由目标模式恢复该比例。

## 八、分章模式

- `ReaderReadingMode.chapter` 是默认值。
- 屏幕只挂载当前章节的纵向 `ListView`，全文仍按章节存储。
- 上一章和下一章分别使用独立预览控制器。
- 预览控制器不写入当前章节进度，并在离屏阶段恢复该章保存位置。
- 当前页、上一章和下一章位于同一个 `Stack`。
- 手指位移由 `ValueNotifier<double>` 驱动，左右平移只承担章节切换。
- 拖动超过距离阈值或速度阈值时提交切章，否则回弹。
- 翻页提交读取目标预览页真实像素和比例，新活动页直接继承。
- 分章模式没有仿真纸张选项，不调用 `_BookLeafCurlPainter`。

## 九、滚动模式

- `ReaderReadingMode.continuous` 使用一个纵向 `CustomScrollView` 连续显示全文。
- 每章是一个具有稳定 `GlobalKey` 的 `SliverMainAxisGroup`。
- 当前章节作为 `CustomScrollView.center`，因此恢复中部章节时不需要先布局整本书之前的内容。
- 章节标题是独立 Sliver，正文通过单项 `SliverList.builder` 在接近视口时才进行段落格式化和构建。
- 已布局章节的 `RenderSliver.geometry.scrollExtent` 被缓存并从锚点向前、向后传播章节起点。
- 当前全局滚动像素通过章节起点和视口高度转换为章节局部像素与比例。
- 新章节标题越过视口顶部时更新 `_chapterIndex`，保存来源章并记录目标章。
- 从目录打开章节或设置重排时，重新以当前章为锚点并按局部比例恢复。
- 滚动模式不注册横向拖动处理器。

## 十、仿真模式

### 按屏分页

- `ReaderReadingMode.simulation` 禁止正文纵向手势，只接受左右翻页。
- 仿真页使用独立 `Stack` 纸页框架，正文 `ListView` 通过 `Positioned.fill` 缩进到安全区和上下留白之间。
- 先从安全区高度中预扣上下各一个正文行高，再选择可容纳的完整正文行数；余下高度平均分给上下两侧，因此通常约一行、最多接近一行半。
- 左上角页眉显示“章节序号/总章数 · 章节名”，字号由正文的 58% 计算并限制在 10–13 px，长标题单行省略。
- `StrutStyle.forceStrutHeight` 让章节大标题与正文使用统一网格行高；段间空行、标题下间距和章尾占位也都是完整行高。
- `LayoutBuilder` 将正文视口高度收敛到行高的整数倍；极矮视口至少保留一个有效正文行，避免负约束。
- 恢复旧像素或比例位置时，偏移按当前字号与行距吸附到最近的完整行边界。
- 缩进后正文 `ScrollController.viewportDimension` 是分页步长；下一页和上一页从当前对齐偏移直接加减该高度，不使用外层整屏网格。
- 同章下一页使用下一个视口网格起点，上一页使用前一个网格起点；章末短页作为独立最后一页。
- 同章目标页使用独立 `_simulationPreviewController`，不会改写活动页进度。
- 跨章向前翻时预热下一章章首，向后翻时预热上一章章末。
- 提交同章翻页时活动控制器直接跳到预览起点并立即记录局部进度。
- 提交跨章翻页时复用分章切章的离章保存顺序和相邻页接管逻辑。

### 几何与纸背

- `_buildChapterModeView` 使用 `_buildSmoothTurnPages` 完成分章左右平移。
- `_buildSimulationModeView` 根据 `simulationPageTurnEffect` 选择渲染器：`simulation` 调用 `_buildCurledBookTurnPages`，`smooth` 调用 `_buildSmoothTurnPages`。
- 两种仿真模式翻页效果共用 `_SimulationPageTarget`、`_simulationPreviewController`、同章屏高步进、跨章预热和提交逻辑，因此只改变画面运动，不改变页边界和进度。
- 仿真模式使用 `Listener` 的原始指针序列跟踪水平位移：移动超过 9 px 且横向位移大于纵向位移的 1.15 倍后立即进入翻页。该路径不依赖正文 `SelectionArea` 的手势竞技场；静止长按仍保留系统选文。
- 前翻时下一页先位于底层，`_ForwardLeafFrontClipper` 沿弯曲斜折线缩小当前页平整正面；当前页右边缘相对折线的反射区域形成大面积卷起纸背。
- 后翻时当前页始终保持完整底层，`_PreviousLeafFrontClipper` 从左至右扩大上一页已铺平的正面；上一页左边缘相对独立折线的反射区域形成领先纸背并继续盖住当前页。
- `_ForwardLeafGeometry` 与 `_PreviousLeafCoverGeometry` 是两套独立三次贝塞尔几何；后翻不是把前翻进度、坐标或变换取反。
- 手指纵向落点控制纸页从上角或下角主导卷起；中段折痕保持明显对角线，翻到起点和终点时卷起纸背自然收拢为零宽度。
- `_BookLeafCurlPainter` 绘制大面积自由纸背、自由边投影、弯曲折痕暗部、柔光、纸张厚度和纸背真实字迹。
- 当前活动页由稳定 `GlobalKey` 的 `RepaintBoundary` 包裹；后翻目标页在手势期间使用另一个 `RepaintBoundary` 捕获上一页的真实内容。
- 章节小字、上下留白和正文位于同一个 `RepaintBoundary`，因此真实快照和纸张背面保持一致。
- 稳定页面主动异步预取快照。指针按下、横向拖动、回弹和提交路径只发起或复用已有 `RenderRepaintBoundary.toImage()` Future，不调用 `toImageSync()`，不等待图像。边界尚未完成绘制时最多等待三个帧周期，截图像素比上限为 1.5。
- 前翻只使用稳定状态已预取的当前页快照；后翻只使用上一页预览完成布局后异步捕获的目标快照，不用当前页字迹冒充上一页。快照状态不阻断拖动、速度判断、回弹或提交。
- 快照围绕折痕上下端点组成的斜轴做二维反射并裁入纸背曲线，完整保留页眉、标题、正文、当前字体、字重、主题和当前屏位置。
- 浅色纸面使用 0.54 的真实页面透射强度，深色纸面使用 0.66；随后分别叠加 0.20 和 0.16 透明度的当前主题纸面遮罩，字迹可辨，同时保持位于薄纸反面的衰减质感。
- 菜单、设置、章节、页面或手势状态变化后使快照失效并重新预取。
- 快照尚未就绪时不会阻断拖动、速度判断、回弹或提交；卷页裁切、折痕、阴影和主题纸背照常绘制，快照完成后仅补充镜像文字。
- 捕获异常保留错误与堆栈输出，供问题定位。
- 纸背快照捕获、手势起点捕获和稳定页预取都以 `simulationPageTurnEffect == simulation` 为前提；选择平滑翻页时直接跳过这些图像工作。

## 十一、设置与字体

- 字号：`16 / 18 / 20 / 22 / 24`，默认 `20`。
- 行距：`1.4 / 1.6 / 1.8 / 2.0 / 2.2`。
- 字重：细、中、粗。
- 页边距：窄、中、宽。
- 段落间距：不空行、空一行，默认不空行。
- 阅读模式：分章、仿真、滚动，默认分章。
- 仿真翻页效果：仿真翻页、平滑翻页，默认仿真翻页；只在仿真模式下展开。
- 主题：跟随系统、浅色、暖色、深色。
- 字体：系统字体、内置宋体、导入字体。
- 内置 `SourceHanSerifSC-Regular.ttf` 包含 65,535 个 glyph 和 44,748 个 Unicode cmap 映射。
- 内置宋体对“细 / 中 / 粗”分别使用 `w400 / w600 / w900`；“粗”再添加一层同色无模糊锐利加厚，确保不与“中”落成相同的静态字面。
- 系统字体和导入字体继续使用原 `w300 / w400 / w600` 映射。
- 模式说明组件保留旧文本和新文本同帧滚动，向后切换时旧项向上离开、新项从下方进入，向前切换时方向反转；不使用 `AnimatedSwitcher` 默认淡变。
- 翻页效果二级选项使用 `AnimatedSize` 在模式说明下方展开或收起，不做透明度淡变。
- 用户字体支持 `.ttf` 与 `.otf`，并进行扩展名、大小和文件存在性检查。
- `FontLoader` 对并发加载去重；字体不可用时回退系统字体。

## 十二、书架、字数与开关书

### 书架与字数

- 书架启动只读取 metadata，正文按需读取。
- 书架使用 `SliverGridDelegateWithFixedCrossAxisCount(crossAxisCount: 3)`，每行固定三本；卡片高宽比、封面内边距、字号和格式标签已按三列宽度收紧。
- 缺少 `wordCount` 时立即渲染书卡，并将书籍加入串行后台队列。
- `WordCountService` 在 isolate 中统计章节标题和正文的非空白 Unicode scalar value。
- 同一本书的并发统计 Future 去重。
- 后台结果只更新 `wordCount`。
- 阅读页已经持有正文时可复用同一统计任务，并实时更新已打开目录。
- 阅读器启动后另行在 isolate 中逐章统计正文，不把章节标题计入章节字数。
- 章节统计 Future 去重，完成结果按书籍 ID、文件大小、解析器版本和章节数在应用会话内缓存。
- 整组章节字数写入轻量 metadata；旧书首次后台补齐，后续启动和开书直接复用，不重新扫描正文。
- 持久化前再次核对 metadata 中的文件大小、解析器版本和章节数，防止旧任务覆盖新解析目录。
- 章节统计不参与开书 Future；目录通过独立 notifier 接收整组结果。
- 普通书架长按只打开三个明确选项：修改名称、移动、删除；修改名称使用完整宽度主操作，移动和删除使用紧凑的图标加小文字按钮。
- 选择“移动”后进入独立整理态，顶部显示“调整顺序”、操作提示和“完成”；返回键与左上角关闭也可退出，普通态长按不直接拖动。
- 整理态使用三列 `Stack` 与 `AnimatedPositioned` 计算书卡坐标；跨过目标书卡时立即更新顺序，相邻书卡使用 310 ms 弹性曲线平滑让位。
- 拖起书卡放大到约 `1.055` 倍并增加阴影和强调描边；原位保留低透明占位，目标位轻微缩小并提供触觉反馈，松手后书卡回弹到网格。
- 拖到视口顶部或底部时书架自动滚动；一次拖动结束后只写入一次 metadata 列表顺序。
- 书卡内容保持实体纸书观感；半透明材质只用于轻量控制层，不对每张封面叠加高成本玻璃效果。
- 整理态顶部使用 20 px 标题、紧凑完成按钮和一行拖动提示；网格改用独立滚动控制器，顶部 padding 为 0，第一排书卡紧接提示出现。

### 主题安全转场

- 开书时从书卡位置展开封面快照。
- 封面以左边缘为轴进行 3D 开页。
- 打开和关闭共用 680 ms 时间线，关闭反向播放。
- 路由使用非 opaque 背景，让书架在收拢过程中连续显露。
- 阅读页主题变化通过共享 `ValueListenable<ReaderThemeColors>` 同步给书架与转场。
- 阅读页、纸面、加载占位、书架和系统栏使用当前阅读主题。
- 关闭前保存进度并恢复书架所需系统栏。
- 封面快照和主题监听器在 `TransitionRoute.completed` 后释放。
- 转场期间吸收指针事件，避免误触底层书架。

## 十三、性能与数据可靠性

- TXT、EPUB、DOCX、章节 JSON、全文字数和逐章字数使用后台 isolate；DOC 的 Android HWPF 提取使用专用工作线程。
- 书架 metadata 与章节正文分离存储。
- 正文和目录使用按视口构建的列表。
- 最近章节的段落拆分结果使用小型 LRU 缓存。
- 章节文件使用原子替换，并支持完整 `.tmp` / `.bak` 恢复。
- 设置、进度、改名、全文字数和逐章字数写入遵循最新状态优先。
- Android 云备份关闭。
- Release 仅包含 `arm64-v8a`，并启用代码与资源收缩。
- 阅读设置底部面板的正向/反向时长为 330/220 ms；书架设置侧栏为 330 ms。
