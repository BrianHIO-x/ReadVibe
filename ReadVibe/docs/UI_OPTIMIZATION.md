# ReadVibe v0.1.7 阅读体验与优化基线

本文档描述 ReadVibe 当前阅读交互、滚动位置、翻页渲染、设置重排、解析性能和本地数据可靠性的实现基线。它不是自动生成的测试报告，也不记录已经删除的测试数量。

任何实现发生变化后，必须根据仓库根目录 `AGENTS.md` 与应用目录 `AGENTS.md` 的规则，同步检查并修正仓库内全部 Markdown。

## 二、优化目标

阅读页的核心约束是“画面连续、位置稳定、数据不串章”：

- 单击菜单不能改变正文位置。
- 调整设置和主题不能让正文回到顶部。
- 返回上一章必须恢复上一章自己的位置。
- 左右拖动时，相邻章节第一次露出就应显示保存进度。
- 翻页提交前后的目标页面必须是同一位置，不能完成动画后再次跳转。
- 双击不能选中文字，长按仍应允许选择和复制。
- 大型 TXT 或 EPUB 的解析和存储不能长期阻塞主线程。

## 三、TXT 解析与排版

### 编码和换行

TXT 解析支持：

- UTF-8；
- UTF-8 BOM；
- UTF-16 LE / BE BOM；
- 常见 GBK 回退；
- CR、LF、CRLF；
- NEL、Unicode 行分隔符和段落分隔符。

解析工作在后台 isolate 中执行，避免 14 MB 级别文件长时间阻塞书架动画。

### 章节识别

- 支持常见中文章节、回目、卷、节和英文 `Chapter` 标题。
- 支持 `# 第1章`、`## 第二章 ##` 和全角 `＃` 等 Markdown 外壳。
- 章节标题显示前删除原始前导半角和全角空格。
- 句号结尾的普通“第一卷……”或“第一节……”正文不作为章节。
- 首个真实章节前的文字保留为“开篇”。
- 没有正文的连续目录项不生成空白阅读页。
- 旧版“全文”记录按解析器版本自动重建，并按整书比例迁移当前进度。

### 段落策略

- 存储层使用单换行分隔自然段。
- 显示层统一去除正文原始前导空格，再添加两格全角首行缩进。
- 默认段落之间不空行。
- 阅读设置顺序固定为“不空行 / 空一行”。
- 空一行只改变显示间距，不重复扩张章节正文文件。

## 四、EPUB 解析

- 在后台 isolate 中解压和解析 EPUB。
- 从 `container.xml` 取得 OPF 路径。
- 读取 metadata、manifest 和 spine。
- 按线性 spine 顺序处理 XHTML。
- 跳过非线性、空白、脚本和样式内容。
- 将块级 HTML 元素转换为适合小说阅读的纯文本换行。
- 对归档条目数、单项大小和总解压体积设置保护边界。

EPUB 当前定位是小说纯文本阅读，不承担复杂 CSS 和图文版式还原。

## 五、菜单与正文布局稳定

### 稳定的组件层级

正文 `ListView` 始终位于同一层 `SelectionArea` 中。菜单打开和关闭不会把列表从一个包装组件移动到另一个包装组件，因此不会重新创建 `ScrollPosition`。

### 菜单短按

阅读页通过原始指针的按下位置、移动距离、抬起位置和持续时间识别短按：

- 单击正文呼出或关闭菜单；
- 移动超过阈值后不再视为单击；
- 纵向滚动、横向翻章和长按选择不会误触菜单。

切换菜单之前立即保存当前像素与比例。布局完成后再次检查同一个控制器，如果系统栏或外层布局造成偏移，则跳回切换前的安全像素。

### 系统栏

- 开书转场开始时保留书架需要的系统栏。
- 阅读页接管后隐藏顶部状态栏。
- 底部手势导航区域始终保留。
- 打开阅读菜单时重新显示状态栏，关闭后恢复沉浸模式。
- 首次布局保存稳定顶部安全区，状态栏切换不会推动正文。

## 六、文本选择行为

当前要求：

- 双击正文禁止选择词语；
- 双击不显示选择手柄和复制工具栏；
- 长按正文仍可选词、拖动选择并复制；
- 纵向滚动和横向翻章不受影响。

实现包含两层保护：

1. 在 `SelectionArea` 子树内部放置双击识别器，让它优先接管第二次点击；
2. 记录两次短按的时间与位置。某些平台如果仍先创建选区，则在工具栏出现前立即调用 `clearSelection()`。

第二层保护只在 300 ms 双击窗口内生效。长按识别晚于该窗口，因此长按选择仍可成立。

## 七、阅读进度状态

### 保存内容

每本书同时保存：

- 当前章节；
- 当前滚动像素；
- 当前归一化阅读比例；
- 每章独立像素映射；
- 每章独立比例映射；
- 最后阅读时间。

从 JSON 读取时会过滤非有限数值、负数、越界比例和无效章节索引。

### 当前章节滚动

- 活动章节控制器监听滚动。
- 滚动时立即更新内存中的 `ReadingProgress` 和最后快照。
- 本地保存使用 500 ms 防抖。
- 页面关闭、应用进入后台或开始翻章时主动排队保存。
- 保存任务串行执行，旧写入不会覆盖更新的状态。

### 离章顺序

横向手势开始时记录：

- 离开的章节索引；
- 离章像素；
- 离章比例。

提交切章时先把离章状态加入保存队列，再切换活动控制器和章节索引，最后保存目标章节。这样不会把旧章节控制器的像素写到新章节。

### 设置重排

字号、行距、字体、字重、页边距和段落间距会改变文档总高度。应用设置前先记录当前比例，重排后按新的最大滚动范围恢复同一比例，不依赖已经失效的旧像素。

### 页面退出

State 销毁时 `ScrollController` 可能已经失去客户端。此时最后一个监听器维护的真实快照仍是权威值，不能回退为 0。

## 八、相邻章节预热

上一章和下一章使用独立预览控制器：

- 预览控制器不注册当前章节的进度保存监听；
- 控制器创建时使用该章节保存像素作为初始值；
- 内容尺寸可用后，优先按保存比例重新定位；
- 预览页在屏幕外完成布局与恢复；
- 主题或排版重建时重新核对预览位置。

翻页提交时读取目标预览页的真实像素和比例，新活动控制器以该像素创建。提交前看到的页面与提交后留下的页面一致，不再发生“先显示章首，动画结束后才跳进度”。

旧活动控制器和旧预览控制器只在新布局挂载后的下一帧释放，避免仍附着时销毁。

## 九、平滑翻页

- 当前页、上一章和下一章位于同一个 Stack。
- 相邻页提前预热并恢复保存位置。
- 手指位移由 `ValueNotifier<double>` 驱动，减少整个阅读页无关区域重建。
- 拖动距离超过 16% 页宽，或速度超过阈值时完成翻章。
- 未达到阈值时使用统一动效曲线回弹。
- 快速打断完成动画时保持章节状态和离章快照一致。

## 十、仿书籍翻页

早期版本只使用垂直裁切与矩形渐变，当前已经替换为曲面纸张模型。

### 几何

- `_BookCurlGeometry` 根据页宽、页高、翻页进度、方向和手指纵向位置生成几何。
- 当前页边界使用三次贝塞尔折痕。
- 手指靠近页面上方或下方时，折痕产生对应倾斜。
- 纸张背面宽度按翻页强度先扩大后收拢。
- 上一章与下一章通过方向镜像共享同一套计算。

### 绘制

- `_BookPageClipper` 裁切仍未翻起的当前页。
- `_BookCurlPainter` 在目标页绘制动态投影。
- 当前页折痕内侧绘制渐变暗部。
- 纸张背面使用与阅读主题匹配的纸色渐变。
- 纸背加入低透明度透印线条，避免形成空白塑料带观感。
- 卷边绘制背面暗线、折痕柔光和模糊阴影。

仿书效果继续使用相邻预览页，因此视觉增强不会牺牲章节进度连续性。

## 十一、设置和字体

- 设置面板使用紧凑分段控件并允许滚动。
- 选项动画先执行，正文重排延迟一个短周期，降低第一次切换卡顿。
- 字体栏目同时保留系统字体和内置宋体。
- 支持导入 `.ttf` / `.otf`，包含扩展名、大小和存在性检查。
- `FontLoader` 并发加载去重。
- 替换字体后清理旧文件。
- 字体文件丢失时安全回退系统字体。

## 十二、书架与开关书动画

- 书架启动只读取元数据，点击书后再读取正文。
- 开书时截取书架封面画面并从原位置展开。
- 封面以左边缘为轴进行 3D 开页。
- 阅读内容在封面展开后接管画面。
- 关闭时先恢复书架所需系统栏，再反向合页回到封面位置。
- 路由转场使用非 opaque 背景，避免关闭时闪黑。
- 动画期间吸收点击，避免误触底层页面。

## 十三、性能和数据可靠性

- TXT、EPUB 和大章节 JSON 编解码使用后台 isolate。
- 书架与正文分离存储，减少启动 I/O 和常驻内存。
- 正文使用 `ListView.builder` 按视口懒加载。
- 最近章节的段落拆分结果使用小型 LRU 缓存。
- 章节文件原子写入，支持 `.tmp` / `.bak` 恢复。
- 设置与进度采用最新写入优先。
- Android 云备份关闭。
- Release 只包含 arm64-v8a，并启用代码与资源收缩。

## 十五、手工回归路径

当前不使用自动化测试。涉及阅读交互时，真机至少检查以下路径：

1. 打开一本已有多个章节和历史进度的书。
2. 随机滚动到章节中段，单击打开菜单，再次单击关闭，确认位置不变。
3. 调整主题、字号、行距、字体、字重、页边距和段落空行，确认仍跟随原阅读比例。
4. 双击正文，确认不出现选区、手柄或工具栏。
5. 长按正文，确认仍能选择和复制。
6. 切换平滑翻页，向下一章拖动到一半，确认目标页第一次露出就是保存位置。
7. 完成翻页，确认动画结束后没有二次跳转。
8. 返回上一章，确认恢复离章位置。
9. 切换仿书籍翻页，分别从页面上部和下部拖动，观察折痕倾斜、纸背、阴影和高光。
10. 快速取消或连续翻章，确认没有章节重叠、控制器异常或进度串写。
11. 退出并重新打开书籍，确认章节和位置恢复。

如果厂商安装安全页要求人工确认，必须由用户在手机上完成；ADB 无法替代该安全确认时，不得把上述真机路径标记为已完成。

## 十六、平台边界

- Android arm64-v8a 是唯一正式目标。
- Windows 目录仅保留占位说明。
- Android 32 位、x86、x86_64 不支持。
- iOS、macOS、Linux、Web 平台目录已删除。
- 当前不包含平板专门布局、复杂 EPUB 版式、书签、批注、搜索、听书、账号或云同步。
