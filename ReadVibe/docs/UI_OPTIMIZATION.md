# ReadVibe 阅读交互实现基线

本文档只描述 ReadVibe `v0.3.0` 当前有效的阅读交互、位置恢复、翻页渲染、目录、主题转场和性能实现。这里不保存旧版本故障过程或已替换方案。

## 一、发布与验证状态

| 项目 | 当前值 |
|---|---|
| 公开版本 | `v0.3.0` |
| 正式 APK | `dist/ReadVibe-Android-v0.3.0-arm64-v8a.apk` |
| ABI | `arm64-v8a` |
| 文件大小 | 38,061,331 字节（约 36.30 MiB） |
| SHA-256 | `F60CDF556B4C5AE371BC42B3E7CDE2BE930E977254B80812693DA1A0F98315BD` |
| 静态分析 | `flutter analyze` 通过 |
| Release 构建 | Android arm64 release 构建通过 |
| 真机检查 | 交付检查时没有连接 ADB 设备，未执行目视验证 |

阅读手势、系统文本菜单、仿书纸背、后台字数刷新和深色转场仍需在 Android 真机逐项确认。未执行路径不得写成已经通过。

## 二、交互目标

- 单击显示或关闭菜单时，正文保持当前位置。
- 调整主题、字号、行距、字重、字体、页边距和段落间距后，正文保持阅读比例。
- 每章保存自己的滚动位置，往返切章不串写。
- 相邻章节第一次进入翻页画面时已经位于保存位置。
- 翻页动画完成后不再发生二次位置跳转。
- 仿书纸背显示当前可见阅读页的真实镜像文字。
- 双击不选择文本，长按只显示五项指定操作。
- 全文字数统计不阻塞书架、开书或目录操作。
- 深色主题的开书与关书转场不插入浅色中间帧。

## 三、解析与排版

### TXT

- 支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM 和常见 GBK。
- 支持 CR、LF、CRLF、NEL、Unicode 行分隔符和段落分隔符。
- 识别常见中文章节、回目、卷、节、英文 `Chapter` 和 Markdown 标题外壳。
- 标题显示前清理前导半角与全角空格。
- 普通句子不会因为包含“卷”或“节”就被识别为标题。
- 首个章节前的有效正文保留为开篇内容。
- 没有正文的连续标题不生成空白阅读章节。
- 纯卷标题保存到后续章节的 `volumeTitle`，用于目录分组。
- 大文件读取、解码、分章和 JSON 编解码在 isolate 中执行。

### 段落

- 存储层用单换行表示自然段。
- 显示层清理正文原始前导空格，再添加两格全角首行缩进。
- 段落间距默认“不空行”。
- 用户可切换为“空一行”，该设置只影响显示布局。

### EPUB

- 在 isolate 中解压和解析。
- 从 `container.xml` 定位 OPF，读取 metadata、manifest 与 spine。
- 按线性 spine 顺序处理 XHTML。
- 跳过非线性、空白、脚本和样式内容。
- 块级 HTML 转换为小说段落换行。
- 归档条目数、单项大小和总解压体积均有保护边界。

## 四、目录显示模型

目录先建立 `_TocDirectory` 显示模型，再交给列表按需渲染：

- 至少一个章节具有明确卷名时，建立卷与章节两级结构。
- 完全没有卷信息时，直接显示单层章节列表。
- 卷标题是一级折叠项，所属章节是缩进的二级可读项。
- 简介、作品简介、作者简介、前言、序言、序章、楔子、引子和开篇等卷外内容位于顶部。
- 后记、尾声、附录和番外等内容保持独立一级项。
- 含正文的卷首页作为卷内可读章节显示。
- 卷初次显示为展开状态。
- 折叠集合以书籍 ID 为作用域保存到 `SharedPreferences`。
- 当前章节位于折叠卷时，目录定位到卷标题并保留折叠状态。
- 删除书籍时同步清理目录折叠数据。
- 标题区通过 `ValueListenable<int?>` 显示章节总数和全文字数。

## 五、菜单与正文位置

### 稳定组件层级

正文 `ListView` 始终位于同一层 `SelectionArea` 内。菜单显隐不会把正文列表移动到另一套组件树，因此不会重新创建 `ScrollPosition`。

### 单击识别

阅读页根据原始指针的按下位置、移动距离、持续时间和抬起位置判断短按：

- 有效单击切换菜单；
- 移动超过阈值后不再判定为单击；
- 纵向滚动、横向翻章和长按选择不触发菜单切换。

菜单变化前立即记录当前像素和阅读比例。布局完成后再次检查同一控制器，如果外层安全区变化造成偏移，则恢复到安全像素。

### 系统栏

- 阅读内容接管后隐藏顶部状态栏。
- 底部手势导航区域保留。
- 打开阅读菜单时显示状态栏，关闭后恢复沉浸状态。
- 阅读页保存稳定顶部安全区，系统栏切换不推动正文。
- 系统栏颜色和图标亮度由当前 `ReaderThemeColors` 统一生成。

## 六、文本选择

### 双击

- `SelectionArea` 子树中的双击识别器接管第二次点击。
- 阅读页记录短按时间与位置；确认双击时清理可能提前建立的选区。
- 长按发生在双击窗口之外，仍可建立选区并拖动手柄。

### 长按菜单

`SelectionArea.contextMenuBuilder` 只构建以下五项：

1. 复制
2. 分享
3. 全选
4. 翻译
5. 搜索

复制、分享和全选复用平台 `ContextMenuButtonItem` 的回调。翻译和搜索由 `SystemTextActionService` 通过 MethodChannel 调用 Android：

- 翻译优先使用 `Intent.ACTION_TRANSLATE`，并提供系统文本处理回退。
- 搜索优先使用 `Intent.ACTION_WEB_SEARCH`，并提供系统浏览器回退。

上下文菜单使用当前阅读主题配色。只有用户主动点击翻译或搜索后，选中文字才会交给系统目标。

## 七、阅读进度状态

### 保存字段

每本书保存：

- 当前章节索引；
- 当前滚动像素；
- 当前归一化阅读比例；
- 每章独立像素映射；
- 每章独立比例映射；
- 最后阅读时间。

反序列化时过滤非有限数值、负数、越界比例和无效章节索引。

### 当前章节

- 活动章节控制器监听滚动并更新内存快照。
- 本地进度保存使用 500 ms 防抖。
- 保存任务串行执行，后续状态不会被先前异步写入覆盖。
- 页面关闭、应用进入后台和开始翻章时主动排队保存。
- 控制器断开后使用最后一个有效快照，不回退为零值。

### 离章顺序

横向手势开始时锁定来源章节索引、像素和比例。提交切章时先保存来源章节，再切换活动章节与控制器，最后保存目标章节状态。

### 设置重排

字体、字号、行距、字重、页边距和段落间距会改变正文高度。设置应用前保存阅读比例，重排后按新的最大滚动范围恢复该比例。

## 八、相邻章节预热

- 上一章和下一章分别使用独立预览控制器。
- 预览控制器不写入当前章节进度。
- 创建时使用该章已保存像素作为初始值。
- 内容尺寸可用后按已保存比例核对位置。
- 预览页在屏幕外完成布局和恢复。
- 主题或排版变化后重新核对预览位置。
- 翻页提交读取目标预览页的真实像素和比例。
- 新活动页挂载后再释放上一组控制器。

## 九、平滑翻页

- 当前页、上一章和下一章位于同一个 `Stack`。
- 相邻页提前预热并恢复自己的保存位置。
- 手指位移由 `ValueNotifier<double>` 驱动，减少阅读页其它区域重建。
- 拖动超过页面宽度阈值或速度达到阈值时完成切章。
- 未达到阈值时沿统一动画曲线回弹。
- 动画被新手势打断时保持章节索引、控制器和离章快照一致。

## 十、仿书籍翻页

### 几何与绘制

- `_BookCurlGeometry` 根据页宽、页高、翻页进度、方向和手指纵向位置生成折页几何。
- 当前页边界使用三次贝塞尔曲线。
- 手指位于页面上部或下部时，折痕沿相应方向倾斜。
- 前翻与后翻通过镜像方向共用几何模型。
- `_BookPageClipper` 裁切仍未翻起的当前页。
- `_BookCurlPainter` 绘制目标页投影、折痕暗部、柔光和纸张厚度。

### 真实文字纸背

- 当前活动页由稳定 `GlobalKey` 的 `RepaintBoundary` 包裹。
- 指针开始横向手势时创建或复用唯一异步 `toImage()` 捕获任务。
- 待绘制状态最多等待三个帧周期。
- 快照围绕实时折痕轴反射，形成纸张背面的镜像内容。
- 标题、正文、字体、主题、滚动位置和折痕倾斜保持一致。
- 镜像内容结合纸色、透明度、方向明暗与投影形成透印效果。
- 纵向滚动、菜单、设置、章节变化、回弹完成和 State 销毁都会使旧快照失效。

### 可用性兜底

- 快照未就绪时，同一手势继续使用平滑页面响应拖动。
- 快照到达后在当前拖动位置切换为曲面纸背。
- 捕获失败不会阻止速度判断、回弹或章节提交。
- 捕获异常保留错误和堆栈输出，便于定位真机渲染问题。

## 十一、设置与字体

- 字号：`16 / 18 / 20 / 22 / 24`，默认 `20`。
- 行距：`1.4 / 1.6 / 1.8 / 2.0 / 2.2`。
- 字重：细、常规、粗。
- 页边距：窄、中、宽。
- 段落间距：不空行、空一行，默认不空行。
- 翻页模式：平滑、仿书籍。
- 主题：跟随系统、浅色、暖色、深色。
- 字体：系统字体、内置宋体、导入字体。
- 内置 `SourceHanSerifSC-Regular.ttf` 包含 65,535 个 glyph 和 44,748 个 Unicode cmap 映射。
- 用户字体支持 `.ttf` 与 `.otf`，并进行扩展名、大小和文件存在性检查。
- `FontLoader` 对并发加载去重；字体不可用时回退系统字体。

## 十二、书架、字数与开关书

### 书架与字数

- 书架启动只读取 metadata，正文按需读取。
- 缺少 `wordCount` 时立即渲染书卡，并将书籍加入串行后台队列。
- `WordCountService` 在 isolate 中统计章节标题和正文的非空白 Unicode scalar value。
- 同一本书的并发统计 Future 去重。
- 后台结果只更新 `wordCount`。
- 阅读页已经持有正文时可复用同一统计任务，并实时更新已打开目录。
- 长按书卡显示改名和删除；改名只更新 metadata 的 `title`。

### 主题安全转场

- 开书时从书卡位置展开封面快照。
- 封面以左边缘为轴进行 3D 开页。
- 打开和关闭共用 680 ms 时间线，关闭反向播放。
- 路由使用非 opaque 背景，让书架在收拢过程中连续显露。
- 阅读页主题变化通过共享 `ValueListenable<ReaderThemeColors>` 同步给书架与转场。
- 阅读页、纸面、加载占位、书架和系统栏使用当前阅读主题。
- 关闭前保存进度并恢复书架所需系统栏。
- 封面快照和主题监听器在 `TransitionRoute.completed` 后释放。
- 转场期间吸收指针事件，避免误触底层书架。

## 十三、性能与数据可靠性

- TXT、EPUB、章节 JSON 和全文字数使用后台 isolate。
- 书架 metadata 与章节正文分离存储。
- 正文和目录使用按视口构建的列表。
- 最近章节的段落拆分结果使用小型 LRU 缓存。
- 章节文件使用原子替换，并支持完整 `.tmp` / `.bak` 恢复。
- 设置、进度、改名和字数写入遵循最新状态优先。
- Android 云备份关闭。
- Release 仅包含 `arm64-v8a`，并启用代码与资源收缩。

## 十五、Android 真机检查清单

1. 在章节中段单击打开菜单，再次单击关闭，确认位置不变。
2. 调整主题、字号、行距、字体、字重、页边距和段落间距，确认继续位于原阅读比例。
3. 双击正文，确认不出现选区、手柄或工具栏。
4. 长按正文，确认只显示复制、分享、全选、翻译和搜索，并逐项检查系统目标。
5. 使用平滑翻页拖动到相邻章节，确认目标页第一次露出就是保存位置。
6. 完成前翻与后翻，确认动画结束后不发生二次跳转。
7. 切换仿书籍模式，从页面上部和下部拖动，确认纸背显示当前可见文字镜像。
8. 在快照尚未完成时立即拖动，确认平滑兜底仍可完成切章。
9. 快速取消和连续翻章，确认没有章节重叠、控制器异常或进度串写。
10. 在手机系统浅色、ReadVibe 深色的组合下关闭书籍，确认全程没有浅色中间帧。
11. 在书内切换深色主题后立即关闭，确认书架底层和系统栏已同步。
12. 导入含简介与多个卷标题的 TXT，确认简介置顶、卷默认展开、章节为二级项且没有空白卷页。
13. 折叠卷并重新打开目录、书籍和应用，确认按书恢复状态。
14. 打开无卷标题的书，确认目录保持单层。
15. 在全文字数统计中立即打开书籍和目录，确认均无需等待，并观察目录原地刷新结果。
16. 长按书卡修改名称，确认书架与阅读页标题更新，正文和进度不变。

如果系统安装安全页要求人工确认，应由用户在设备上完成；无法执行的步骤必须保持“未验证”状态。
