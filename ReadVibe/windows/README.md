# Windows 平台状态

ReadVibe `v0.5.6` 当前只发布 Android `arm64-v8a` APK，最低支持 Android 8.0（API 26）。本目录仅保留平台状态说明，不是 Windows 构建工程，也不提供 Windows 运行或打包命令。

当前正式产物：

```text
../dist/ReadVibe-Android-v0.5.6-arm64-v8a.apk
```

如果平台范围发生变化，必须同步更新版本配置、工程文件、构建流程、发布产物以及仓库内全部 Markdown。
