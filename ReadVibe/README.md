# ReadVibe Android 应用

ReadVibe 是使用 Flutter 与 Android Kotlin 实现的本地离线阅读器。当前版本为 `v0.6.3`，正式目标为 Android `arm64-v8a`，最低支持 Android 8.0（API 26）。

## 文件支持

| 格式 | 导入与阅读方式 |
| --- | --- |
| TXT | 在 Dart isolate 中读取并识别编码、分章，进入统一小说阅读器 |
| EPUB | 按 OPF spine 解析 XHTML、NAV/NCX 目录、必要 CSS 与包内图片，正文按 TXT 规则排版并进入统一小说阅读器 |
| DOCX | 在 Dart isolate 中提取 WordprocessingML 正文并分章，进入统一小说阅读器 |
| DOC | 由 Android 工作线程使用 Apache POI HWPF 本地提取正文并分章，进入统一小说阅读器 |
| PDF | 复制到应用私有目录，由 Android `PdfRenderer` 逐页渲染并进入固定版式阅读器 |

所有解析与阅读均在本机完成。EPUB 只读取压缩包内部资源和 base64 图片，不加载远程 CSS 或图片。

## 书架

- 手机布局每行三本书，书卡显示格式、章节或页数、阅读比例和全文字数。
- 解析完成即可打开书籍；全书与每章字数由后台 isolate 静默计算并持久化。
- 长按书卡显示“修改名称 / 智能分章 / 移动 / 删除”。
- “智能分章”面向章节识别异常的 TXT、DOCX 和 DOC 书籍：抽取候选标题行发给 DeepSeek 分析格式，校验通过后在本机重新分章，原分章自动备份并可一键恢复；密钥只保存在本机，不上传完整正文。
- “修改名称”只修改书架显示名。
- “移动”进入独立整理界面；拖动时保留原位占位，相邻书卡动画让位，靠近边缘时自动滚动，完成后保存顺序。
- “删除”清理书籍元数据、正文、阅读进度、目录状态以及由应用管理的 EPUB 图片目录或 PDF 文件。
- 全局设置可导入 TTF/OTF 字体、控制阅读时保持亮屏，并重新选择翻译或网页搜索默认应用。

## 小说阅读器

TXT、EPUB、DOCX 和 DOC 共用同一个阅读页面。

### 分章模式

- 当前章纵向滚动。
- 左右手势切换上一章或下一章。
- 每章分别保存滚动位置；离开章节前先保存当前章进度。
- 文本选择可在当前章内向上、向下连续扩展，到章首或章尾停止。

### 滚动模式

- 全书章节在同一个纵向滚动流中连续排列。
- 跨章时同步当前章节、章节局部进度和菜单页眉。
- 文本选择可随系统边缘滚动跨章扩展，直到整本书边界。

### 仿真模式

- 页面顶部显示章节序号和章节名；正文上下保留纸页留白。
- 当前字号、字体、字重、行高、页边距、段落空行和 EPUB 富内容共同参与固定纸页分页。
- 正文视口吸附完整行边界，页起点固定按一整屏递增；恢复位置、相邻页预览、跨章翻页和提交进度使用同一分页模型。
- 章节最后一页不足一整屏时只在正文后显示空白纸面，下一次前翻直接进入下一章，不会再次显示内容更少的重叠末页。
- “仿真翻页”由原始指针位移驱动。左滑前翻时当前页沿直线折回；右滑后翻时上一页从纸背展开并覆盖当前页。
- 双向运动纸页都有垂直折痕、直线纸边、阴影和与纸页内容一致的镜像反向字迹。
- 页面快照异步预取；快照尚未生成时，镜像页面层提供纸背字迹，翻页操作不被阻断，也不回退为左右平移。
- “平滑翻页”保留相同分页和进度模型，但不建立纸背快照。
- 当前页形成文本选区后，页面滚动范围固定在当前像素，选择手柄不能拖动底层正文或触发跨页。

### 模式切换与位置恢复

阅读器记录当前视口顶部正文的章节、段落和段内字符。进入仿真模式时，目标字符直接落到包含它的纸页；离开仿真模式时，同一字符所在行恢复到滚动视口顶部。切换过程重新创建对应阅读控制器，不复用不同排版的像素位置。

菜单、主题、字体、字号、字重、行高、页边距、段落空行和搜索跳转也使用字符锚点恢复，页面可见前由遮罩保护控制器重建过程。

## EPUB 富内容

EPUB 解析器按 OPF spine 读取章节，并优先使用 EPUB3 NAV 或 EPUB2 NCX 中的章节名称作为目录标题。导航缺失或损坏时，依次使用正文语义标题和文档标题。正文中的 `h1` 至 `h6`、标题角色/类名元素、视觉标题，以及与目录标题一致的正文首段作为 EPUB 标题块参与实际排版；它存在时阅读器不再另外绘制目录标题，因此不会在一章开头显示两份标题。

普通正文段落使用与 TXT 相同的字体、字号、字重、行高、字距、首行缩进和段落空行设置。标题仍保留 EPUB 层级、颜色、背景、强调与对齐；正文中的粗体、斜体、下划线和可读颜色也继续保留。这样 EPUB 与 TXT 的阅读密度和操作逻辑一致，同时不丢失有意义的出版样式。

解析器在单次导入中缓存已解码外部 CSS、解析后的规则以及每个元素的匹配声明，并合并相邻的相同样式文本。结构化块落盘时不再重复写入一份完整纯文本；重新加载时从块恢复搜索、字数和字符定位所需的纯文本，降低大文件导入时的解析和序列化开销。

当前 CSS 解析范围包括：

- 标签、类、ID、后代和直接子级选择器。
- 文档内 `<style>`、行内 `style`、包内外链样式表和递归 `@import`。
- 标题对齐、相对字号、字重、斜体、下划线、文字颜色、背景颜色和包内背景图。
- 行内粗体、斜体、下划线及可读颜色；普通段落的行高、字距、首行缩进和段落间隔由 ReadVibe 阅读设置统一控制。

当前图片范围包括 JPEG、PNG、GIF、WebP、BMP、base64 图片和 CSS 包内背景图。图片存入应用私有 EPUB 目录，并作为分章、滚动和仿真模式中的正文块参与布局。

## PDF 阅读器

- 横向逐页浏览并显示当前页码和总页数。
- 页面使用 `InteractiveViewer` 支持双指缩放与平移。
- 保存当前页和全书页码比例，重新打开后恢复到已读页。
- 渲染任务按页码和目标宽度缓存，缓存保持有限数量；渲染失败的页面允许再次加载。

## 目录

- 顶部显示全书章节数和全文字数。
- 每个可读章节右侧显示非空白 Unicode 字数。
- 存在明确卷标题时显示卷与章节两级目录。当前卷标题固定在列表顶部，在下一卷到达时替换。
- 简介、前言等卷外内容排列在卷目录之前。
- 卷展开状态按书保存；打开目录时定位当前章节并保持所属卷标题可见。
- 章节标题左侧只保留排版留白，不添加两位数或全局位置装饰编号。

## 全文搜索

TXT、EPUB、DOCX 和 DOC 的全文搜索入口始终可用。

每次提交关键词时，后台 isolate 直接扫描当前 `Book.chapters`：

- 连续 Unicode 空白规范为一个空格。
- 拉丁字母匹配不区分大小写。
- 结果保存章节、非空段落序号、原始 UTF-16 字符位置、命中文字和上下文。
- 规范化位置映射回原始段落，点击结果后按字符锚点跳转。
- 单次最多返回前 500 条；达到上限时界面提示增加关键词。

## 文本选择与系统应用

- 双击正文不会选中文本。
- 长按形成非空、非纯空白选区后显示复制、分享、全选、翻译和搜索。
- 选择活动期间，系统选择手势优先于章节切换、翻页和底层正文拖动。
- 翻译界面横向显示已安装并能接收文字的 DeepSeek、ChatGPT、Gemini、Claude、Microsoft Copilot 和 Perplexity，使用 APK 内置应用图标。
- 翻译内容固定包装为 `翻译如下内容：“所选文字”`，并由 Android 显式启动系统返回的处理组件。
- 网页搜索横向显示 Edge、Chrome 和系统浏览器文字卡片。
- 翻译和网页搜索都能记住默认目标；默认组件失效时会清除记录并重新显示选择界面。

## 阅读设置

| 项目 | 当前选项 |
| --- | --- |
| 阅读模式 | 分章、滚动、仿真 |
| 仿真子选项 | 仿真翻页、平滑翻页 |
| 主题 | 系统、浅色、暖色、深色 |
| 字号 | 16、18、20、22、24；默认 20 |
| 字体 | 系统字体、内置宋体、本地导入字体 |
| 字重 | 细、中、粗 |
| 页边距 | 窄、中、宽 |
| 段落 | 不空行、空一行；默认不空行 |
| 其他 | 行高、保持屏幕常亮 |

设置与书内位置分开持久化。删除或损坏的导入字体元数据会自动清理并回到系统字体。

## 本地数据

- `SharedPreferences` 保存书架元数据与顺序、阅读设置、进度和目录展开状态。
- 分章正文、EPUB 图片、PDF 源文件和导入字体保存在应用私有目录。
- 同一偏好键的异步写入串行执行，只有最新状态可以落盘。
- 字数结果写回前会核对格式、源文件大小、解析版本和章节数，避免旧后台任务覆盖新导入内容。
- DeepSeek API 密钥保存在本地偏好设置中；智能分章前的原章节目录备份在应用私有目录，恢复或删除书籍时清理。
- 应用内更新只请求 GitHub Releases 的版本信息，下载的安装包经 SHA-256 校验后交给系统安装器。
