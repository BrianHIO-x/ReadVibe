# ReadVibe

ReadVibe 是一款面向 Android 的本地离线阅读器，支持导入 TXT、EPUB、PDF、DOCX 和 DOC 文件。TXT、EPUB、DOCX 与 DOC 共用分章、滚动和仿真三种阅读模式，并提供目录、全文搜索、文本选择、字体与排版设置；PDF 则按原始版式逐页阅读。

当前公开版本为 `v0.6.6`，适用于 Android 8.0（API 26）及以上的 `arm64-v8a` 设备。书架顺序、阅读进度和个人设置都会自动保存在本机，重新打开书籍后可以继续阅读。

## 开始使用

1. 下载并安装 [ReadVibe v0.6.6 Android 安装包](dist/ReadVibe-Android-v0.6.6-arm64-v8a.apk)。首次安装时，请按 Android 系统提示允许当前来源安装应用。
2. 打开 ReadVibe，点击书架上的导入按钮，从设备中选择 TXT、EPUB、PDF、DOCX 或 DOC 文件。
3. 点击书卡开始阅读；在阅读页打开菜单后，可以使用目录、全文搜索和阅读设置。长按书卡可以修改名称、调整顺序或删除书籍。

## 隐私保护

ReadVibe 不需要账号，也不提供云同步。书籍解析、正文搜索、字数统计和阅读记录均在设备本地完成，书籍正文不会上传；EPUB 中的远程资源也不会加载。应用只会为检查和下载新版本连接 GitHub Releases；只有当你主动使用翻译、分享或网页搜索时，所选文字才会交给你明确选择的第三方应用或浏览器处理。
