# ReadVibe Android 应用

ReadVibe 是面向本地小说阅读的 Flutter Android 应用。TXT、EPUB、DOCX、DOC、阅读进度、字体、设置和书架元数据均在设备本地处理。

## 功能说明

### 书架

- 启动时只加载轻量书架元数据，点击书籍后再读取章节正文。
- 书架使用固定三列网格，手机每行显示三本书。
- 书卡针对三列宽度收紧封面内边距、标题字号、格式标签和底部元信息，超长文字安全省略。
- 书卡显示作者、章节数、阅读比例和全文字数。
- 缺少字数时立即显示可点击书卡，并在后台逐本统计。
- 长按书籍固定打开三个选项：修改名称、移动、删除；修改名称为完整宽度的主要操作，移动和删除为图标加小文字的紧凑按钮。
- 选择“移动”后进入独立整理态，书架标题切换为“调整顺序”，可通过返回键、左上角关闭或“完成”退出。
- 整理态支持直接拖动书卡；拖起时书卡抬升并增加阴影，原位保留半透明占位，相邻书卡沿三列网格弹性让位，靠近上下边缘时自动滚动。
- 松手后书卡回弹到目标位并将 metadata 列表的新顺序持久化。
- 整理态顶部缩为 20 px 标题、紧凑操作栏和一行拖动提示；书卡网格改用独立滚动控制器并紧接提示显示，不继承普通书架的滚动留白。
- 改名只原子更新 metadata 中的 `title`，不会重写大型章节 JSON。
- 删除书籍同步清理正文、阅读进度和目录折叠状态。

### 后台全文与章节字数

- 统计范围为全部章节标题与正文。
- 按 Unicode scalar value 计数，并排除 Unicode 空白字符。
- 使用 isolate 执行，避免占用 UI 主线程。
- 同一本书的并发统计任务去重；书架队列一次处理一本书。
- 开书 Future 不等待字数结果。
- 结果只更新 metadata 的 `wordCount` 字段，不覆盖并发完成的书名修改。
- 阅读页通过 `ValueNotifier<int?>` 将结果实时推送给已经打开的目录。
- 阅读器启动后同时在 isolate 中统计每一章正文的非空白 Unicode 字符，不把章节标题重复计入章节字数。
- 章节统计不阻塞开书或目录；未完成的章节行显示“统计中…”，完成后通过 `ValueNotifier<List<int>?>` 原地刷新。
- 同一本书的章节统计 Future 和会话内结果会去重；完成结果写入轻量 metadata，后续重新启动或打开书籍时直接复用。
- 写回章节字数前核对文件大小、解析器版本和章节数，过期后台任务不会覆盖已经重新解析的目录。

### TXT 导入

- 支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM 和常见 GBK。
- 支持 CR、LF、CRLF、NEL、Unicode 行分隔符和段落分隔符。
- 识别 `第1章`、`第一回`、`Chapter 1`、`# 第1章` 等常见标题。
- 普通句子不会仅因包含“卷”或“节”而被当作章节。
- 首个章节前的有效内容保留为开篇内容。
- 连续标题没有正文时不生成可跳转的空白章节。
- 纯卷标题写入后续章节的 `volumeTitle`，用于建立目录层级。
- 大文件读取、解码、解析和 JSON 编解码在 isolate 中执行。

### EPUB 导入

- 解压和解析在 isolate 中执行。
- 从 `META-INF/container.xml` 定位 OPF。
- 读取 metadata、manifest 和 spine。
- 按线性 spine 顺序提取 XHTML 文本。
- 跳过空白内容、脚本、样式和非线性页面。
- 块级 HTML 转换为适合小说阅读的段落换行。
- 对归档条目数、单项体积和总解压体积设置保护边界。

EPUB 按小说纯文本模式呈现，不复刻原文件的复杂 CSS 和图文排版。

### DOCX 与 DOC 导入

- DOCX 使用已有 `archive` 依赖解压，在 isolate 中读取 WordprocessingML 的 `word/document.xml`。
- DOCX 的段落、表格文字、换行和制表符按原文档顺序转成纯文本，再复用 TXT 分章与排版规则。
- 旧版二进制 DOC 由 Android MethodChannel 调用 Apache POI 5.5.1 HWPF，在单独工作线程提取正文，不占用 UI 线程。
- DOC/DOCX 单文件上限为 128 MB；DOCX 同时限制 ZIP 条目数、总解压体积和主 XML 体积。
- 加密、损坏、空文档或无正文的文档会返回明确导入错误。

### 阅读页手势

| 手势 | 行为 |
|---|---|
| 单击正文 | 打开或关闭顶部、底部菜单 |
| 双击正文 | 不选择文本，不显示选择工具栏 |
| 长按正文 | 选择文本，显示五项系统操作 |
| 上下滑动 | 分章模式滚动当前章；滚动模式连续阅读全文 |
| 左右滑动 | 分章模式切章；仿真模式逐页翻阅 |
| 点击目录章节 | 从章首打开所选章节 |

三种模式的正文都位于稳定的 `SelectionArea` 层级。菜单切换前保存当前章节、局部像素和比例，布局完成后核对活动控制器，避免系统栏或模式组件变化带来位置偏移。

顶部阅读菜单不显示书名，分两行显示当前章节序号与章节名。分章切章、滚动模式跨章和仿真翻页更新活动章节时，顶部信息随同一次界面状态更新。

### 文本选择菜单

长按选择工具栏只显示：

1. 复制
2. 分享
3. 全选
4. 翻译
5. 搜索

复制、分享和全选复用 Flutter 在 Android 上的平台选择回调。翻译和搜索的可用目标由 Android 系统 `PackageManager` 实时解析，ReadVibe 前端只负责将系统结果筛选为产品规定的精简面板：

- Android 分别查询 `ACTION_SEND`、`ACTION_PROCESS_TEXT` 和 `ACTION_TRANSLATE` 的真实处理 Activity；前端只显示其中已安装且能接收文字的 DeepSeek、ChatGPT、Gemini、Claude、Microsoft Copilot 和 Perplexity。
- 发送给 AI 的内容固定为 `翻译如下内容：“所选文字”`。
- Android 查询 `ACTION_VIEW` 的真实网页处理 Activity；前端始终只显示 `edge / chrome / 系统浏览器` 三行，未安装项禁用，不显示其他应用。
- Edge、Chrome 和 AI 目标使用系统返回的真实包名与 Activity 显式启动，原生层启动前再校验白名单和组件；“系统浏览器”使用未限定包名的原生 `ACTION_VIEW` Intent。
- 翻译面板使用高度 120 的横向滑动卡片，DeepSeek、ChatGPT、Gemini、Claude、Microsoft Copilot 和 Perplexity 使用 `assets/images/ai/` 中的官方 192×192 WebP 图标；通用机器人图标和单选圆点已删除。
- 搜索面板使用同样的横向滑动交互，但不保存浏览器图标；每张卡使用 `SEARCH WITH`、浏览器字标、选中描边和底部强调线组成纯文字品牌视觉。
- 两个面板都可勾选“记住并默认打开”；保存后下次点击直接跳转。书架全局设置中的“重新选择默认应用”可清除记录。

### 目录

- 有明确卷信息时，卷为一级菜单，章节为缩进的二级菜单。
- 没有卷信息时直接显示单层章节列表。
- 简介、作品简介、前言、序言、序章、楔子等卷外内容位于目录顶部。
- 后记、尾声、附录和番外等内容保持独立一级项。
- 卷默认展开，点击卷标题折叠或展开。
- 折叠集合以书籍 ID 为作用域写入 `SharedPreferences`。
- 当前章节属于折叠卷时，目录定位到卷标题并保留用户选择。
- 标题区显示章节数与全文字数；统计完成后无需关闭目录即可刷新。
- 每个可读章节最右侧显示该章正文的字数，数字使用千位分隔并右对齐；卷标题继续显示其包含的项目数。

### 阅读进度

每本书保存：

- 当前章节索引；
- 当前滚动像素；
- 当前归一化阅读比例；
- 每章独立像素映射；
- 每章独立比例映射；
- 最后阅读时间。

三种模式共用这组每章状态。活动章节变化时更新内存快照，本地写入使用防抖与串行队列。开始横向翻页、跨越连续滚动章节边界、应用进入后台或关闭阅读页时主动保存。

### 分章模式

- 默认阅读模式。
- 全文保持分章，屏幕只显示一个可纵向滚动的章节。
- 左右拖动使用平移切换上一章或下一章。
- 设置中不提供仿真翻页开关；分章模式只负责稳定的章节滚动和切换。
- 上一章和下一章使用独立预览控制器。
- 预览页在屏幕外完成布局并恢复该章保存位置。
- 翻页提交时读取预览控制器的真实像素和比例。
- 新活动页从预览位置接管，动画前后保持同一画面位置。
- 当前页与相邻预览页位于同一 `Stack`，水平位移由 `ValueNotifier<double>` 驱动。
- 松手后根据位移比例和速度完成切章或回弹。

### 滚动模式

- 全部章节位于同一个纵向 `CustomScrollView`。
- 以进入模式时的当前章节作为 `center` 锚点，打开时无需先测量前面全部章节。
- 每个章节使用独立 `SliverMainAxisGroup`，正文接近视口时才构建。
- 向上或向下跨过章节标题时，自动更新当前章节索引。
- 连续流中的全局像素换算为当前章节局部像素和比例，再写入通用阅读进度。
- 从目录选择章节时重新建立该章锚点，并从章首开始。

### 仿真模式

- 正文锁定纵向手势，左右拖动按活动视口高度逐页推进。
- 选中仿真模式时，设置面板在模式说明下方展开“翻页效果”二级选项，提供“仿真翻页 / 平滑翻页”。
- 二级选项默认为“仿真翻页”，使用 `simulationPageTurnEffect` 按名称持久化；退出仿真模式后暂时隐藏，再次进入时恢复上次选择。
- 每一页都使用独立纸页框架；正文上下根据屏幕剩余高度平均分配留白，通常约一行、最多接近一行半，比固定两行更紧凑。
- 左上角以小字显示“章节序号/总章数 · 章节名”；长章节名单行省略，不挤压正文。
- 仿真模式为章节大标题、正文、空一行段间距和章尾占位设置统一的强制行高，使整个章节内容落在完整文字行网格上。
- 正文视口高度只取完整行数，分页步长读取该 ListView 的真实 `viewportDimension`，页面边缘不会裁到半行文字。
- 旧版本保存的任意像素位置或其他模式的比例位置，进入仿真模式时先吸附到最近的完整行边界。
- 前后翻页从当前对齐位置直接加减一个正文视口；章末短页仍安全贴合内容末尾。
- 同一章内的目标页使用独立预览控制器并直接定位到下一屏或上一屏。
- 到达章节边界时，下一章预热在章首，上一章预热在章末。
- 页面位置按视口网格计算，前翻后再后翻会回到同一页起点。
- 选择“仿真翻页”时，每一次有效拖动都进入 `_buildCurledBookTurnPages`：当前页或上一页使用独立的大面积斜向纸叶裁切，并同步绘制折痕、投影、高光和纸张厚度。当前页只在阅读页稳定时异步预取，手指按下、横向拖动、回弹和提交不执行同步整屏截图。
- 仿真模式不再依赖正文 `SelectionArea` 所在的横向手势竞技场；原始指针移动超过 9 px 且以横向为主后立即开始跟手翻页，未移动的长按仍由系统建立文本选区。
- 左滑前翻使用“当前页向左卷走”层级：下一页位于底层，当前页右边缘相对斜折线反射形成大面积自由纸背，页面本体不做水平平移。
- 右滑后翻使用独立的“上一页盖回”层级：当前页全程留在底层，上一页的平整区域从左边缘向折痕增长，折起纸背继续覆盖右侧当前页，不使用前翻的反向动画。
- 仿真翻页不会因为快照未完成而退回平滑平移；只有用户显式选择“平滑翻页”才会改用 `_buildSmoothTurnPages`。纸背快照经当前斜折轴反射后使用透纸衰减，页眉、标题与正文字迹保持可见。
- `_ForwardLeafGeometry` 计算前翻时当前页从右向左卷走的斜折线、平整正面，以及由右边缘相对折线反射得到的纸背区域。
- `_PreviousLeafCoverGeometry` 独立计算上一页从左向右覆盖时的反向倾斜折线、已铺平正面，以及由左边缘反射得到的领先纸背，不通过符号取反复用前翻几何。
- `_ForwardLeafFrontClipper` 与 `_PreviousLeafFrontClipper` 分别裁切两套运动中的纸页正面。
- `_BookLeafCurlPainter` 沿弯曲折痕绘制投影、暗部、柔光、纸张厚度和真实反射字迹。
- 当前活动页由稳定 `GlobalKey` 的 `RepaintBoundary` 包裹。
- 稳定当前页和后翻目标页分别只复用一个异步 `toImage()` 捕获任务，像素比最高限制为 1.5，减少栅格线程压力和瞬时图像内存。
- 前翻纸背捕获当前可见页；后翻为上一页的目标预览增加独立 `RepaintBoundary`，在预览完成布局后捕获它的真实页面。
- 纸背快照围绕折痕上下端点组成的斜轴做二维反射，并裁入当前曲线折页区域；前翻只使用当前页快照，后翻只使用上一页快照，不显示错误页面的字迹。
- 镜像保留真实页眉章节小字、标题、正文、上下留白、字体、主题和滚动位置；浅色/深色主题分别使用不同的透纸强度，再叠加薄纸遮罩，让反面文字可见但不像第二个正面。
- 稳定页面主动预取快照；滚动、菜单、设置、章节或手势结束后立即使快照失效。
- 快照尚未完成或捕获失败时，同一手势仍直接显示仿真卷页和当前主题纸背；快照完成后只在当前拖动位置补上纸背镜像文字，不更换动画类型。
- 选择“平滑翻页”时，当前页和目标页按手指水平位移同步平移；同章目标页、跨章预热页、完整行分页和进度提交都复用仿真模式原模型。
- 平滑翻页不需要卷页纸背，因此不会捕获或预取 `toImage()` 快照，也不保留之前的仿真纸背图像。

### 阅读设置

| 设置 | 选项 |
|---|---|
| 字号 | 16、18、20、22、24；默认 20 |
| 行距 | 1.4、1.6、1.8、2.0、2.2 |
| 字重 | 细、中、粗 |
| 页边距 | 窄、中、宽；默认中 |
| 段落间距 | 不空行、空一行；默认不空行 |
| 阅读模式 | 分章、仿真、滚动；默认分章 |
| 仿真翻页效果 | 仿真翻页、平滑翻页；默认仿真翻页，仅仿真模式显示 |
| 主题 | 跟随系统、浅色、暖色、深色 |
| 字体 | 系统字体、内置宋体、导入字体 |

字号、行距、字体、字重、页边距、段落间距和阅读模式会改变正文结构。应用设置前保存当前章节及局部比例，重排后由目标模式恢复同一位置。

阅读模式的分段选择器按“分章 / 仿真 / 滚动”排列。下方模式说明使用与选项方向一致的纵向滚动替换，旧文本滚出的同时新文本滚入，全程不改变透明度。

“翻页效果”二级选项使用 `AnimatedSize` 从模式说明下方展开或收起，不使用淡入淡出。仅更改翻页渲染路径，应用前保存当前章节与局部阅读比例，重建页面后恢复同一位置。

阅读设置底部面板打开时长为 330 ms、关闭为 220 ms；书架设置侧栏为 330 ms。这些时长只做小幅加速，不改动效曲线或设置应用顺序。

### 字体

- “系统字体”和“内置宋体”始终并列显示。
- 内置 `SourceHanSerifSC-Regular.ttf` 保留 65,535 个 glyph 和 44,748 个 Unicode cmap 映射。
- 内置宋体的“细 / 中 / 粗”分别请求 `w400 / w600 / w900`；“中”即原“粗”效果，“粗”在最重请求上增加一层同色锐利加厚，避免三档中出现两档完全相同。
- 系统字体和导入字体继续使用其自身的 `w300 / w400 / w600` 映射。
- 支持导入 `.ttf` 和 `.otf`。
- `FontLoader` 对并发加载去重。
- 字体文件不可用时安全回退系统字体。

### 开书、关书与主题

- 开书时截取书架中的封面画面，并从书卡位置展开。
- 封面以左侧为轴进行 3D 开页，阅读内容随后接管画面。
- 关闭使用同一条 680 ms 时间线反向播放。
- 路由纸面、加载占位、阅读页、书架和系统栏共享当前 `ReaderThemeColors`。
- 书内切换主题时，书架底层和转场主题同步更新。
- 路由采用非 opaque 背景，使书架在页面收拢时连续显露。
- 封面快照和主题监听器保留到 `TransitionRoute.completed` 后释放。
