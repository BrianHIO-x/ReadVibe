# ReadVibe Flutter 应用协作规则

本文件适用于 `ReadVibe/` 内的 Flutter 代码、Android 工程、资源、文档和发布产物，并服从仓库根目录 [`../AGENTS.md`](../AGENTS.md)。

## 一、当前发布基线

- 公开版本：`v0.3.0`。
- `pubspec.yaml`：`version: 0.3.0`。
- Android 基础 `versionCode`：`14`。
- arm64 分包清单：`versionCode=2014`，`versionName=0.3.0`。
- 正式 APK：`dist/ReadVibe-Android-v0.3.0-arm64-v8a.apk`。
- 正式 ABI：`arm64-v8a`。

公开版本必须使用三段式语义版本。Android 构建编号单独递增，不得附加到公开版本号或文件名。

## 二、Markdown 同步

每次代码、资源、依赖、配置、版本、构建、产物或交互发生变化后：

1. 执行 `rg --files -g '*.md'` 获取实际 Markdown 清单。
2. 逐一核对版本、功能、命令、路径、平台状态、验证结论和交叉链接。
3. 删除已被当前实现替代的故障过程、旧版本流水和无效功能说明。
4. 文档必须只描述当前实现、当前限制、当前产物和真实验证状态。
5. 新增、移动、重命名或删除 Markdown 时，同步更新两级 `AGENTS.md` 和根 README 的文档导航。

当前必须检查：

- `../AGENTS.md`
- `../README.md`
- `AGENTS.md`
- `README.md`
- `docs/UI_OPTIMIZATION.md`
- `windows/README.md`

## 三、平台与构建

- 当前唯一正式目标是 Android `arm64-v8a`。
- 不扩大 ABI 或平台范围，除非用户明确要求。
- Flutter 代码改动至少执行：

```powershell
flutter analyze
flutter build apk --release --split-per-abi --target-platform android-arm64 --build-name 0.3.0 --build-number 14
```

- 发布前核对 APK 的 `versionName`、`versionCode`、`native-code`、文件大小和 SHA-256。
- `dist/` 只保留当前规范命名的正式 APK。

## 四、阅读状态

- 每章分别保存滚动像素和归一化阅读比例。
- 离章前先保存来源章节，再切换活动章节和控制器。
- 相邻章节使用独立预览控制器，并在进入画面前恢复自身位置。
- 翻页提交沿用预览页真实位置，不能先显示章首再二次跳转。
- 菜单、主题、字体、字号、行距、字重、页边距、段落间距和翻页模式变化不得造成回顶。
- 退出、切到后台和切章时使用最后一个有效滚动快照，不能用零值覆盖真实进度。

## 五、阅读交互与渲染

- 单击正文只控制阅读菜单。
- 双击正文不得触发文本选中。
- 长按正文菜单只显示复制、分享、全选、翻译和搜索。
- 复制、分享和全选使用平台选择回调；翻译和搜索调用 Android 系统服务。
- 仿书籍纸背必须来自当前可见阅读页的真实镜像快照。
- 纵向滚动、菜单、设置、章节和手势状态变化后，旧快照必须失效。
- 快照捕获不得阻断横向拖动；快照未就绪时使用可操作的平滑过渡。
- 深色主题下，阅读页、纸面、路由底层、书架和系统栏必须保持同一套深色配色。
- 封面快照、主题监听器和转场资源在 `TransitionRoute.completed` 后释放。

## 六、目录、字数和书架

- 明确卷标题存在时显示两级目录；没有卷标题时保持单层目录。
- 简介、前言、序言等卷外内容作为顶部一级项。
- 纯卷标题保留为章节结构元数据，不生成空白阅读页。
- 卷默认展开，折叠状态按书持久化；删除书籍时同步清理。
- 全文字数统计章节标题和正文中的非空白 Unicode 字符。
- 字数在 isolate 中逐本后台执行，书架、开书和目录不得等待结果。
- 书架长按提供改名和删除；改名只修改 metadata，不重写章节正文。

## 七、设置、字体与排版

- 字号固定为 `16 / 18 / 20 / 22 / 24`，默认 `20`。
- 段落间距顺序为“不空行 / 空一行”，默认“不空行”。
- 字体入口同时保留“系统字体”和“内置宋体”。
- 内置宋体必须保留完整现有 Unicode cmap；不能以删除生僻字形的方式缩小包体。
- 用户字体只接受可读取的 `.ttf` 和 `.otf`，并安全复制到应用目录。
- 设置导致正文高度变化时按阅读比例恢复位置。

## 八、存储与隐私

- 正文、元数据、设置、字体和阅读进度只保存在设备本地。
- 不引入账号、云同步、正文上传或隐式网络传输。
- 章节文件使用原子替换；设置、进度、改名和字数写入采用最新状态优先。
- 后台字数写回只能更新 `wordCount`，不能覆盖并发完成的书名修改。

## 九、验证与交付

- 当前项目不保留自动化测试目录、测试缓存或 `flutter_test`。
- 未经用户明确要求，不创建自动化测试，也不报告测试通过数量。
- 阅读手势、系统文本菜单、主题转场和进度恢复优先在 Android 真机检查。
- 没有连接设备时，必须明确列出尚未执行的真机路径。
- 发布前确认全部 Markdown 已同步，且没有过期实现、旧版本修复流水、失效链接或不真实的验证结论。
- 未经用户要求，不提交、不暂存、不推送 Git 改动。
