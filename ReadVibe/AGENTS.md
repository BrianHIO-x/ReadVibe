# ReadVibe Flutter 应用协作规则

本文件适用于 `ReadVibe/` 内的 Flutter 代码、Android 工程、资源、文档和发布产物，并服从仓库根目录 [`../AGENTS.md`](../AGENTS.md)。

## 一、当前发布基线

- 公开版本：`v0.5.6`。
- `pubspec.yaml`：`version: 0.5.6`。
- Android 基础 `versionCode`：`31`。
- arm64 分包清单：`versionCode=2031`，`versionName=0.5.6`。
- 正式 APK：`dist/ReadVibe-Android-v0.5.6-arm64-v8a.apk`。
- 正式 ABI：`arm64-v8a`。

公开版本必须使用三段式语义版本。Android 构建编号单独递增，不得附加到公开版本号或文件名。

## 二、Markdown 同步

每次代码、资源、依赖、配置、版本、构建、产物或交互发生变化后：

1. 执行 `rg --files -g '*.md'` 获取实际 Markdown 清单。
2. 逐一核对版本、功能、命令、路径、平台状态、验证结论和交叉链接。
3. 删除已被当前实现替代的故障过程、旧版本流水和无效功能说明。
4. 文档必须只描述当前实现、当前限制、当前产物和真实验证状态。
5. 新增、移动、重命名或删除 Markdown 时，同步更新两级 `AGENTS.md` 和根 README 的文档导航。

当前必须检查：

- `../AGENTS.md`
- `../README.md`
- `AGENTS.md`
- `README.md`
- `docs/UI_OPTIMIZATION.md`
- `windows/README.md`

## 三、平台与构建

- 当前唯一正式目标是 Android `arm64-v8a`。
- 最低系统为 Android 8.0（API 26）。
- 不扩大 ABI 或平台范围，除非用户明确要求。
- Flutter 代码改动至少执行：

```powershell
flutter analyze
flutter build apk --release --split-per-abi --target-platform android-arm64 --build-name 0.5.6 --build-number 31
```

- 发布前核对 APK 的 `versionName`、`versionCode`、`native-code`、文件大小和 SHA-256。
- `dist/` 只保留当前规范命名的正式 APK。

## 四、阅读状态

- 每章分别保存滚动像素和归一化阅读比例。
- 离章前先保存来源章节，再切换活动章节和控制器。
- 相邻章节使用独立预览控制器，并在进入画面前恢复自身位置。
- 翻页提交沿用预览页真实位置，不能先显示章首再二次跳转。
- 菜单、主题、字体、字号、行距、字重、页边距、段落间距和阅读模式变化不得造成回顶。
- `ReaderReadingMode` 固定为 `chapter / simulation / continuous`，界面显示“分章 / 仿真 / 滚动”，默认 `chapter`。
- 分章模式只使用单章纵向列表和左右平移切章；不得在这个模式中暴露仿真翻页开关。
- 滚动模式使用以当前章节为锚点的全文纵向 Sliver 流，跨章时保存来源章并更新目标章局部进度。
- 仿真模式锁定纵向手势，按活动视口高度计算上一页和下一页，同章页面使用独立预览控制器。
- 仿真模式选中时展开 `SimulationPageTurnEffect` 二级设置，界面显示“仿真翻页 / 平滑翻页”，默认 `simulation`，选择按名称持久化。
- 仿真页使用独立纸页面框：正文上下动态分配约一行到一行半的留白，左上角小字显示章节序号、总章数和章节名。
- 仿真正文使用强制行高的统一网格；标题行、正文行、空行和章尾占位都必须占用完整网格高度。
- 仿真模式的 `ScrollPosition.viewportDimension` 必须是完整行高的整数倍；恢复位置吸附到行边界，翻页目标按当前偏移加减一个视口。
- 退出、切到后台和切章时使用最后一个有效滚动快照，不能用零值覆盖真实进度。

## 五、阅读交互与渲染

- 单击正文只控制阅读菜单。
- 阅读菜单顶部显示当前章节序号和章节名，不显示书名；三种模式的活动章节变化必须实时反映到顶部栏。
- 双击正文不得触发文本选中。
- 长按正文菜单只显示复制、分享、全选、翻译和搜索。
- 复制、分享和全选使用平台选择回调；翻译以 Android `PackageManager` 对 `ACTION_SEND / ACTION_PROCESS_TEXT / ACTION_TRANSLATE` 的实际解析结果为数据源，Flutter 再只保留 DeepSeek、ChatGPT、Gemini、Claude、Microsoft Copilot 和 Perplexity。原生启动前重新校验白名单与显式组件，发送提示词固定为 `翻译如下内容：“所选文字”`。
- 搜索以 Android `ACTION_VIEW` 的实际解析结果为数据源，面板固定只显示 `edge / chrome / 系统浏览器` 三项；Edge 和 Chrome 使用显式系统组件，系统浏览器使用原生未限定 Intent。两种操作均可记住默认目标并在下次直接打开，全局设置提供清除默认目标入口。
- 翻译目标使用横向 `ListView` 卡片，内置 `assets/images/ai/` 中六个官方 WebP 图标，不显示通用机器人或单选圆点；搜索目标同样使用横向卡片，但只显示文字品牌、描边和强调线，不引入浏览器图标资源。
- 仿真前翻使用垂直直线折痕与直线纸边裁切当前页并显露下一页；纸张不使用贝塞尔曲线、斜折或波浪形自由边。
- 仿真后翻删除独立覆盖渲染器；上一页作为运动纸页，以 `leafProgress = 1 - progress` 反向复用前翻的 `_StraightLeafGeometry`、正面裁切、纸背裁切和光照路径。
- 前翻纸背对应当前页，后翻纸背对应上一页；两者均围绕当前垂直折痕精确水平镜像。实际快照可用时显示 `RawImage`，快照未就绪时显示绑定独立控制器的同章节、同偏移镜像页面，浅色和深色主题下都不得出现无字空白纸带。
- 仿真模式使用原始指针跟踪横向位移，超过阈值后直接驱动 `_SimulationPageTarget`，同时通过共享阻断状态清除并持续禁止 `SelectionArea` 的选区、工具栏和手柄；未发生横向拖动的长按仍保留系统选文。
- 纵向滚动、菜单、设置、章节和手势状态变化后，旧仿真纸背快照必须失效。
- 仿真翻页效果稳定后主动异步预取当前页快照。后翻目标建立后异步捕获上一页快照。指针按下、横向拖动、回弹和提交不得调用 `toImageSync()` 或等待图像任务；快照未就绪时由镜像页面层立即提供透纸文字，不得自动调用平滑视图。
- 仿真模式在 `simulation` 效果下调用 `_buildStraightBookTurnPages`；双向共用 `_StraightLeafGeometry`、`_StraightLeafFrontClipper`、`_StraightLeafBackClipper` 与 `_StraightPaperPainter`，后翻只反转几何进度。`smooth` 效果只调用 `_buildSmoothTurnPages`。两者共用 `_SimulationPageTarget`、预览控制器和进度提交。
- 活动页与所有预览页的列表键必须包含各自控制器身份和阅读布局类型；提交同章翻页时先跳转活动控制器，再撤销预览与拖动状态。
- 仿真模式与其他阅读模式互相切换时必须创建新的 `ScrollController`，目标布局完成前使用主题纯色遮罩，完成后按章节比例恢复并在仿真模式吸附到完整行。
- 平滑翻页不得捕获、预取或保留纸背快照；切换效果前必须保存当前章节和局部比例，重排后恢复位置。
- 深色主题下，阅读页、纸面、路由底层、书架和系统栏必须保持同一套深色配色。
- 封面快照、主题监听器和转场资源在 `TransitionRoute.completed` 后释放。

## 六、目录、字数和书架

- 明确卷标题存在时显示两级目录；没有卷标题时保持单层目录。
- 简介、前言、序言等卷外内容作为顶部一级项。
- 纯卷标题保留为章节结构元数据，不生成空白阅读页。
- 卷默认展开，折叠状态按书持久化；删除书籍时同步清理。
- 全文字数统计章节标题和正文中的非空白 Unicode 字符。
- 章节字数只统计该章正文中的非空白 Unicode 字符；目录中每个可读章节的最右侧显示结果。
- 章节字数通过 isolate 后台统计，结果未就绪时显示非阻塞占位，完成后原地刷新并写入轻量 metadata；写回前必须核对文件大小、解析器版本和章节数，不能让旧任务覆盖新目录。
- 字数在 isolate 中逐本后台执行，书架、开书和目录不得等待结果。
- 书架网格固定三列，书卡封面、格式标签、元信息和进度条必须在手机三列宽度下无溢出。
- 书架普通态长按只显示“修改名称 / 移动 / 删除”三个选项；修改名称为完整主操作，移动和删除使用紧凑的图标加小文字按钮。
- 只有选择“移动”后才进入独立整理态；整理态使用三列坐标动画，拖起卡片显示抬升阴影和原位占位，相邻卡片弹性让位，边缘拖动自动滚动，松手后回弹并以 metadata 列表顺序持久化。
- 整理态标题字号固定为 20，顶部只保留紧凑标题栏和单行拖动提示；网格使用独立滚动控制器并从提示下方立即开始。
- 返回键、左上角关闭和“完成”用于退出整理态；普通态长按不得同时承担直接拖动，改名只修改 metadata，不重写章节正文。
- 导入支持 TXT、EPUB、DOCX 和 DOC。DOCX 使用 Dart `archive` / XML 在 isolate 内提取正文；DOC 使用 Android Apache POI HWPF 在单独工作线程提取文本。

## 七、设置、字体与排版

- 字号固定为 `16 / 18 / 20 / 22 / 24`，默认 `20`。
- 段落间距顺序为“不空行 / 空一行”，默认“不空行”。
- 字体入口同时保留“系统字体”和“内置宋体”。
- 内置宋体必须保留完整现有 Unicode cmap；不能以删除生僻字形的方式缩小包体。
- 字重文案为“细 / 中 / 粗”。内置宋体的映射为 `w400 / w600 / w900`，其中“中”继承原“粗”的效果，“粗”增加同色锐利加厚以与“中”区分；系统和导入字体保留自身字重映射。
- 阅读模式说明文字随选项顺序纵向滚入、滚出，不使用透明度交叉渐变。
- 用户字体只接受可读取的 `.ttf` 和 `.otf`，并安全复制到应用目录。
- 设置导致正文高度变化时按阅读比例恢复位置。
- 阅读设置底部面板打开 330 ms、关闭 220 ms；书架设置侧栏为 330 ms，不得为提速破坏位置保护或主题连续性。

## 八、存储与隐私

- 正文、元数据、设置、字体和阅读进度只保存在设备本地。
- 不引入账号、云同步、正文上传或隐式网络传输。
- 章节文件使用原子替换；设置、进度、改名和字数写入采用最新状态优先。
- 后台全文字数写回只能更新 `wordCount`；逐章字数写回只能更新 `chapterWordCounts`，两者都不能覆盖并发完成的书名修改或新解析目录。
